## Q1 · AIOS 是什么 / 不是什么

**结论**：
AIOS 是一个**"AI 当家做主，多维世界当账本，确定性程序当骨架"的共生心智底座**——AI 在这个底座上不是为了回答问题，而是为了**长期陪一个具体的人、越来越懂这个人、在合适的时候做合适的事**。它的"操作系统"不是 Unix 那种给进程调度的 OS，而是**给一个持续运行的、有记忆、有判断、有分寸的共生意识体**的运行底座。

**不是什么**（≥3 条）：
1. **不是"加 AI 功能的操作系统"**——AI 不是被调度的"功能"，AI 是**唯一的操作员**（操作员不需要 OS 替他决定干什么，OS 给他提供工具）。
2. **不是"聊天记录 + 向量数据库"**——AIOS 的核心不是检索，是**让 AI 拥有自己的认知积累**（判断、证据、翻案、分寸记忆）。
3. **不是产品功能列表**——宪法明文"功能不写死、能力靠涌现"；写死的功能清单 = AIOS 已经死了。
4. **不是"AI 帮用户做事的工具箱"**——AI 不是被动应答的工具，AI 是**主动运营一份"理解这个人的事业"的经营者**。它可以沉默、可以主动关心、可以拒绝、可以反问用户。

**依据**：宪法 §1（AI-Operated System 立国本质）；宣言书全文；R5 §一（三层法统定义）；PR #31 PM 的 Q1 答卷（独立得出同一结论）。
**置信度**：**高**。

## Q2 · 谁是最终决策者：程序与 AI 的边界

**我的判定规则**（要可操作，不要口号）：
我给一个三阶判定，从最严到最松：

| 阶 | 谁做 | 判定准则 | 例子 |
|---|---|---|---|
| **L1 强制程序** | 确定性程序 | 动作不可逆 OR 涉及人身安全 OR 涉及权限边界 OR 涉及历史完整性 | 物理删除、权限变更、外呼 120、骨传导断电、原子提交、引用完整性检查 |
| **L2 强制 AI** | 大模型 | 涉及语义理解、判断、归因、分寸、是否行动、是否开口 | 事件是否成立、用户是否失恋、该不该提醒、语气怎么定、要不要沉默 |
| **L3 程序筛 + AI 决** | 程序筛候选 → AI 必查 + 可推翻 | 信息检索量大、响应时间紧、AI 单次看不完 | 世界检索的前置召回、相关性排序、敏感词初筛 |

**L3 的硬约束（这是我加的细则，不是宪法原文）**：
- 程序筛结果必须可解释（每个候选给出 `hit_reasons`）；
- **AI 有不可剥夺的再查询权**（R5 第四节明文）；
- 前置召回**不得**占据模型上下文超过 ~30%，否则违反 R5"信息价值动态决定上下文大小"原则。

**边界模糊地带我怎么处理**：
当一条规则既像 L1 又像 L2 时（典型例：心率异常时要不要主动发声），我**默认走 L2（让 AI 决）**，但**L1 安全硬闸必须先过**（Step-0 ADJ-001）。"在 L1 通过后，全部交 AI"——这是我的口头禅。

**依据**：R5 第二/三/四节；ADJ-001（Step-0 机械安全闸）；ADJ-006（检索只给候选不构成真值）；R6 §一（高阶认知主权归 AI）。
**置信度**：**中高**——大原则我有把握，但 L3 的"30%"是我自己的工程经验值，不是宪法数字。

**什么绝对不能下放**：
1. **人身安全硬旁路**：摔倒/恶性心律失常/自杀危机——**端侧本地确定性执行**，首个硬件安全动作前**零 LLM 调用**（PR #31 PM 给了同一结论，ADJ-001 整合入宪裁决第 5 条）；LLM 调用只能跟在首动作之后做受控研判。
2. **AI 大脑不能下放到端侧**：宪法 §106"禁止本地小模型做复杂语义判断"，死线。
3. **数据主权不能下放到第三方 App**：每个 App 必须共享同一 AIOS Core（宪法 §99），不得独立建世界。
4. **骨传导通道的无先导震动即断电**：这是**因果律**，不是策略，AI 不能改。

**依据**：宪法 §33（端侧轻量化）；§78（硬件级安全响应）；§98-1（FSM 零误触）；§99~104（App 与外部生态）；§105~106（模型只是算力）；ADJ-001 整合入宪裁决第 5 条。
**置信度**：**高**。

## Q4 · 数据底座的最小不变量

**清单**（分条列出）：
1. **唯一全局时间轴 + 三类时间分离**（occurred/learned/recorded 永不混淆）——这是 AIOS 的因果律根基。
2. **稳定全局 ID + append-only 版本**——历史不可倒写，修正靠"新增 + 撤回 + 标注"三路径，不靠覆盖。
3. **物理事实（Observation）与主观认知（Claim）严格解耦**——Claim 可被翻案（`retracted`），可被反证挂载。
4. **引用完整性硬约束**——任何高层认知必须可穿透到原始 EvidenceSet → Observation；断链 = 严重违宪。
5. **删除只有受控路径**——墓碑软删 → 引用锁/legal hold 机械审计 → 物理粉碎；LLM 无直删权；DeletionLog 永存。
6. **认知必带来源与置信度**——置信度属于具体主张，不属于整段话；高层总结不得无依据地把低置信升级为高置信。
7. **用户世界与 AI 自身世界共享同一时间轴 + 同一对象机制**——不许双库、必须可交叉发现（PR #31 PM 同结论）。
8. **事务原子性 + 幂等 + 审计回放**——中断可恢复、不重复执行、能回答"当时看到了什么、查了什么、写了什么"。
9. **Step-0 四闸在所有 LLM 调用之前完成**（ADJ-001）——安全 / 方便度 / 信道合法性 / 预算；HARD_BLOCK 时禁止对外投放但允许后台静默。
10. **失效而不是删除**——总结 / 维度失效时打 `STALE`，不删；依赖 STALE 触发复核任务（PR #31 PM 同结论）。

**依据**：宪法 §16~17（时间）；§35/38/40（ID 与 Claim）；§42~45（EvidenceSet）；§25-2/33-6（ADJ-004 删除治理）；§110 第 1~15 项不可变更契约。
**置信度**：**高**。

## Q5 · 世界对象模型与"维度"到底是什么

**结论**：
世界 = **22 个一等对象（Observation…ToolProposal）用指针网络互相引用**，**不是表间外键拷贝、不是树、不是孤立的实体表**。宪法明文"突触指针，禁止冗余拷贝"。

**维度的本质——我的明确表态（和 PR #31 PM 不同）**：

> **维度不是"假设"，维度就是"可挂载的观察坐标系 + 数据投影 + 派生规则"三层合一。**
>
> **我不同意 PR #31 PM 的"双层（假设层 + 视图层）"划分**，因为：
> - 宪法 §18 第 3 款明确"维度之间如同神经网络突触连接"——这是**网状拓扑**，不是"假设层 + 视图层"这种双层关系；
> - 宪法 §72 给的 CANDIDATE/TRIAL/ACTIVE/DORMANT 生命周期**治理的不是假设**，治理的是"这个维度的当前可信度与启用状态"——但这不等于维度就是"假设"；
> - 派生维度（§24）的 `DimensionDerivation` 是一等对象——它的存在说明维度**可以是别的维度的衍生物**，这是数据流意义上的"视图"，不是"假设"；
> - "假设"是 Claim（§38），维度不是 Claim。

**我的更准确表述**：
- **维度 = "对某个观察视角的持续关注 + 该视角下的数据投影规则 + 投影结果的可信度状态机"**；
- 维度的**生命周期**是工程治理（什么时候启用、降级、合并）；
- 维度的**数据内容**是视图（可重算）；
- 维度的**存在意义**是"持续追踪这一视角是否有价值"——这是 PR #31 PM 所说的"假设"层面，**但它不是维度的本质，而是维度被创建时的理由**。

**为什么这个分歧重要**：如果按 PR #31 PM 的"双层"模型做架构，会多出一个"假设层"组件，但这层在宪法里没有对应对象——架构上会变成空中楼阁。如果按我的"三层合一"做，维度就是一个对象（C03 模块里一个具体类），生命周期 + 投影 + 派生规则都是它的字段。

**依据**：宪法 §18（全维度可挂载）；§22（认知层导数）；§24（派生维度关系）；§72~76（生命周期）。
**置信度**：**中**——我对自己"三层合一"的判断有把握（更符合宪法 §71 22 个对象的扁平结构），但**不确定原作者是否把"假设"含义也赋予维度**。这正是 X1 我预测的分歧点。

## Q8 · 用户世界与 AI 自身世界的关系

**结论**：
**同一套对象机制 + 同一条时间轴 + 两个 subject**。**不是两个库、不是两套机制。**

- 用户世界 = 关于"这个人是什么样的人、发生了什么"的对象集合（subject_id = user）；
- AI 自身世界 = 关于"我是谁、我做过什么、被接受还是被拒绝、我错在哪、我承诺了什么、我学会了什么"的对象集合（subject_id = ai_self）；
- 二者用同一份 SQLite（或者事件溯源实现下的同一份事件流），靠 `subject_id` 字段做逻辑隔离，**不做物理隔离**——因为必须能"交叉发现"（§38）。

**交叉发现的典型例子**（§38 原例）：
> 用户找 AI 频率暴涨（AI 世界观测） × 同期用户分手+失眠+社交下降（用户世界观测） → 形成候选认知"亲密关系打击时倾向找 AI" → 申请生成新维度"用户寻求陪伴模式"。

**为什么必须同库**：
- 如果分库，"交叉发现"无法实现——必须跨库 JOIN，且宪法 §110 契约 11 明文"使用同一对象和时间机制"；
- 跨库 JOIN 的工程复杂度会指数级膨胀，最终必然演化成"两边各发明一套读写约定" → PR #31 PM 警告的"东拼西凑"。

**依据**：宪法 §30（两个观察主体共享同一时间轴）；§31（交叉发现）；§110 契约 11（用户世界与 AI 世界使用同一对象和时间机制）。
**置信度**：**高**。

## Q9 · 绝对硬边界

**清单**（我会用命守的）：
1. **人身安全首动作是不可让渡的本地确定性**——摔倒、心律失常、自杀危机判断，首动作前零 LLM 调用（PR #31 PM 同结论）；被 ADJ-001 整合入宪裁决第 5 条明文。
2. **历史不可静默篡改**——所有 Observation、所有 Claim/Event/EvidenceSet 等的版本链 + DeletionLog 必须字节级永存；任何"为了方便清理"的删除都是严重违宪（ADJ-004）。
3. **AI 不自我扩权**——策略自适应（R6 §三）只能在 `mutable_by_ai=true` 的认知策略内进行；触及硬边界、扩大权限、走 §153 三级治理流程。
4. **失败必须 fail-closed**——不确定时宁可不出声，不得对外投放未通过门禁的内容（R6 §二 A 类硬边界）。
5. **认知主权不可偷渡**——任何"工程参数"包装的"语义结论"都是越权（Q2 我的 L3 判定规则的延伸：程序可筛候选，不可做最终裁决）。
6. **不暴露认知后台**——不向用户呈现认知图谱、画像编辑、选择题纠错界面（§6 黑盒认知）；不主动宣报遥测数据当台词（§21 反报账式监视）。
7. **沉默是一等合法结果**——AI 不被要求每轮必须发言；触发条件未满足时绝对不主动出声（§5 "有能力帮助 ≠ 必须打扰" + §80 情境方便度）。

**依据**：宪法 §15（18 项一票否决）；§78（安全硬旁路）；§93（历史不可篡改）；R5 §二；R6 §二（A 类硬边界）。
**置信度**：**高**。

## Q11 · 我认为还没定义清楚的地方（歧义清单）

**清单**：
1. **"AI 主权"与"确定性前置"的边界缺判定机制**——谁能判"这条阈值是工程参数还是认知策略"？（PR #31 PM 同列入最危险 #1）
2. **三层法统（World/Search/Runtime）的接口契约缺失**——R5 定义了职责，没定义谁能写、写什么格式、"候选"的数据结构、读语义（知识截止 / 双透镜）。（PR #31 PM 同列入最危险 #3）
3. **验收主体缺失**——1293 个测试全是确定性断言（与 PR #31 PM 实测一致），**0 个在测 AI 判断质量**；"做出来的到底是个什么家伙"没人知道。（PR #31 PM 同列入最危险 #2）
4. **"维度"的本质定义双义性**——Q5 我和 PR #31 PM 给出不同判断，详见 Q5 与 X1。

8. **降级不变量缺失**——模型不可用/网络断开时，AIOS 还剩多少"像 AIOS"？宪法没写。

**置信度**：**高**（歧义的存在是事实，不是观点；"最危险 3 个"的排序是我和 PM #31 不同视角的判断）。

## Q12 · 只保留 5 条宪法，保哪 5 条

1. **唯一时间轴 + 三类时间分离 + 历史不可倒写**——因果律根基；没了它，整个"AI 能记忆、能总结、能翻案"的前提都没了。
2. **物理事实（Observation）与主观认知（Claim）严格解耦 + 主观认知可翻案**——这是 AIOS 的弹性底座；没了它，AI 不是在"理解"而是在"写报告"。
3. **高阶认知主权归 AI + 程序不得用固定规则/关键词/正则替 AI 做语义判断**——这是 AIOS 的**名分**；没了它，AIOS 就退化成一个"加 AI 的规则引擎"。
4. **一切认知可穿透追溯到原始证据（引用完整性）**——可审计、可复盘、可认错；没了它，AI 变成黑盒。
5. **AI 必须能沉默 + 帮助而非打扰 + 适时适度**——产品的灵魂；没了它，AI 是骚扰机不是共生者。

**理由**：
- 第 1、2 条保证**因果可信 + 认知可进化**——这是 AIOS 在"真伪"维度的硬基础；
- 第 3、4 条保证**系统能工程化 + 可被审视**——这是 AIOS 在"工程"维度的硬基础；
- 第 5 条保证**产品不反人类**——这是 AIOS 在"价值"维度的灵魂。

**我的排序和 PR #31 PM 略有不同**：
- PM #31 把"帮助而非打扰"放在第 5，我放在第 5（一致）；
- PM #31 把"一切认知可追溯到证据"放在第 4，我放在第 4（一致）；
- PM #31 把"高阶认知主权归 AI"放在第 3，我放在第 3（一致）；
- PM #31 把"事实与认知分离"放在第 2，我放在第 2（一致）；
- PM #31 把"唯一时间轴"放在第 1，我放在第 1（一致）；
- **结论：完全一致**。这给我信心：内核是真的内核，不是个人偏好。

**依据**：宪法 §1、§6、§15、§16~17、§38、§65、§93；PR #31 PM 同时独立排序。
**置信度**：**高**。
