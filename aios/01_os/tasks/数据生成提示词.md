# AI 生活数据集生成提示词（可复用）

> 用途：给任何 AI（或本指挥官）生成 AIOS 的大规模模拟生命事件数据集，用于流水线压测与认知系统调试。

## 提示词正文

```
你是一个模拟人生数据生成器。请生成一位中国都市男性「林川，32 岁，互联网公司产品经理」
连续 90 天的腕上 AI 终端事件流，要求：

1. 事件五元组齐全：id(uuid)、ts(秒级时间戳，全天唯一)、source、type、content
2. 事件类型与来源：speech(对话)、vital(体征)、motion(动作)、message(社交消息)、
   payment(消费)、schedule(日程)、env(位置/环境变化)、book(阅读)
3. 真实生活节律：
   - 工作日 07:30 起床 → 08:30 通勤 → 09:00-18:30 工作（会议/方案/客户沟通）→
     19:00 晚餐/健身/社交 → 22:00 阅读/娱乐 → 23:30 睡眠（睡眠期仅每小时 1 条体征）
   - 周末无会议，外出/家务/長睡，事件密度减半
4. 固定人物：小王(同事)、张总(重要客户)、李经理(上级)、小雅(女友)、小陈(下属)、王医生
5. 真实细节：消费有金额（午餐 25-40 元、咖啡 18 元、打车 30 元）、会议有主题
   （AIOS 项目评审、Q3 路线图、客户交付）、对话有上下文连贯性（张总的交付交付周期
   话题贯穿 90 天）、健康有趋势（连续加班后静息心率上升）
6. 数量：每工作日 400-500 条、周末 200-300 条，总计 36000+ 条
7. 禁止：占位文本（"事件123"）、重复模板句、时间戳冲突

输出格式：JSON 数组，每条 {"delay_s":0,"topic":"evt.sim.<type>","event":{五元组}}
```

## 本项目执行说明

- M1 班车由指挥官直接执行本提示词（生成器：simulator/gen_dataset.py）
- 数据用途：①流水线压测（3.6 万事件全链路吞吐）②人生树真实感填充（90 天可钻取）
- 宪法约束自动生效：无事件不记录（睡眠期稀疏）、秒级时间戳、授权源检查
