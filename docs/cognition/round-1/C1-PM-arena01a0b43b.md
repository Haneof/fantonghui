## Q1 · AIOS 是什么 / 不是什么

**结论**：AIOS 是**一个大模型（唯一操作员）与一个具体真人共生活几十年的生活空间**：确定性程序负责提供一个"不会撒谎、不会消失、可以被审计"的世界；AI 负责在这个世界里理解这个人、判断该做什么；产品不是一组功能，而是**对这一个具体的人的持续理解 + 让人心悦诚服的托底**。

**不是什么**（≥3 条）：
1. 不是 RAG 聊天壳（检索几段→塞 prompt→回答，R5 §十一明文禁止退化为这个）；
2. 不是规则引擎/自动化助手——正则、词典、固定状态机**不得产出语义结论**（"用户失恋了""这事很重要"只许 AI 说）；
3. 不是用户画像标签系统——存的是"发生过什么 + 我当时怎么理解 + 后来怎么改判"，不是标签表；
4. 不是一个 AI 矩阵——同一个 AI 进不同专业场所（App），不做多个 AI 各持一个世界；
5. **不是监视系统**（独立增补，与 C 差异点）：用户感受到的是"陪伴"，不是"被监控"；14-2 反报账式监视感 + 宣言§二（"你给我打标签了吗"）是老大原话级红线，零误触是因果律不是标语。

**依据**：统一终版第一条 + 第〇编（宣言§一~§四）；R5 第八十五条之三 §一/§十一；第十四条之二。
**置信度**：**高**。（"不是什么"前 4 条与 C1-Q1 收敛，第 5 条独立。）

## Q2 · 谁是最终决策者：程序与 AI 的边界

**我的判定规则**（可操作）：
1. **不可逆 / 涉人身 / 涉权限**的动作 → 确定性程序执行，AI 只有"意图权"：意图先排队候选池，经机械审计（引用锁/类别/legal hold/权限）后由机械 Worker 执行。ADJ-004 两阶段墓碑就是这条规则的样本实现。
2. **产出语义结论**（情绪/重要性/关系/意图/语气/分寸）→ 一律归 AI；程序只许给"候选 + hit_reasons"，且 **AI 可推翻**（前置召回不垄断记忆入口）。
3. **判定测试题**（每条新代码必问）："这段代码是在给 AI 提供可靠工具，还是在偷偷替 AI 做判断？"后者且非安全/物理约束 → 方向错误（R5 §二）。

**独立补充（答 C 的 Q11-1"缺判定机制"）**：参数归类用**"判错成本承担者"**规则——
> 判错可恢复（误报、打扰、多查一次）→ 成本由体验承担 → **C 类认知策略**，AI 可在证据+版本+回滚下自调；
> 判错不可恢复（漏掉安全、证据断链、误物理删除）→ 成本由人承担 → **A 类硬边界**，程序守死、fail-closed。

**边界模糊地带**：一律往"给 AI 工具"侧靠；拿不准宁可让 AI 多判断一次。
**依据**：R5 §二/§四、R6 §二/§三、ADJ-001/004/006、第八十五条之六 #5；实测：`runtime_policy.json` 的 7 条 hard_rules 全部落在"不可恢复成本"侧（0 次 LLM、≤50ms、无 epoch 即断电）。
**置信度**：**高**（规则）；**中**（具体划线位置，如前置召回预取几条）。

## Q3 · 系统的身体边界（端 / 云 / App / 设备）

**结论**：

| 层 | 承担 | 绝对不做 |
|---|---|---|
| 端侧（手环/手机） | 采样、降噪、ASR 转写、声纹指纹、图像语义化、格式化、FSM、震动/骨传导执行、安全硬旁路**首动作** | 复杂语义判断；本地小模型（第 106 条死刑） |
| 云端大模型 | 全部高阶认知、生成、写回决策 | 直接物理动作；自我扩权 |
| App | 定义领域/目标/工具/界面，产生领域数据 | 拥有独立用户世界或独立 AI |
| 外部设备 | 传感与执行 | 参与认知 |

**什么绝对不能下放**：
1. 人身安全首动作：端侧本地确定性，**首个硬件安全动作前 0 次 LLM/World 调用、≤50ms**，不得被冷却/预算/抑制器/AI 策略屏蔽（85-6 #5 裁决；首动作完成后方可进入受控 EmergencyDialogueJudge 研判）；
2. 历史写入的原子性与引用完整性；
3. 无通知 epoch 时投放通道断电（`false_playback_without_epoch=0`，85-4）。

**依据**：第 33/78/98-1/104-1/105/106 条；85-6 #5；实测：`runtime_policy.json` 的 `p0_*` 5 条硬边界。
**置信度**：**高**（与 C1-Q3 收敛）。

## Q4 · 数据底座的最小不变量

**清单**：
1. 唯一全局时间轴 + 三类时间分离（occurred/learned/recorded）；
2. 稳定 ID + append-only 版本链：历史不可倒写，修正只走"新增 revision / 撤回 / 追加标注"（31-3 RetrospectiveAnnotation），不覆盖旧字符串；
3. 物理事实（Observation）与主观认知（Claim）严格分离；Claim 可翻案、可挂反证；
4. 引用完整性：任何高层认知可穿透到原始证据；**出土兼容**——查询已粉碎 ID 必须返回 Tombstone，不许"不存在"或断链（ADJ-004）；
5. 删除唯一受控路径：墓碑软删（≥30 天+一虚拟周）→ 机械审计 → 机械 Worker 物理粉碎；**LLM 无直删权**；每删必留 DeletionLog 终身对账；
6. 认知必带来源与置信度，置信度挂在**具体主张**上；
7. 双主体（用户世界/AI 自身世界）共用同一对象机制、同一时间轴；
8. 事务/幂等/回放：中断可恢复，且系统必须能回答"当时看到什么、查了什么、写了什么"（R5 §十）。

**依据**：第 16/17/31-3/35/38/93 条、25-2、33-6、第 110 条 15 项契约、R5 §十；实测：M0 参考实现 `aios_core_r2_reference/src/aios_core/storage/sqlite_store.py` 为 append-only `object_revisions`。
**置信度**：**高**（1~7 宪法明文；8 的实现细节中）。

## Q8 · 用户世界与 AI 自身世界的关系

**结论**：**同一套对象机制 + 同一条时间轴 + 两个 subject**，不是两个库两套机制。
- 用户世界："他是什么样的人、发生了什么、我当时怎么理解"；
- AI 自身世界："我是谁、我在哪错了、我被接受/拒绝/忽略了什么、我承诺了什么、我学会了什么用世界的方法"；
- 二者**交叉发现**（用户求助频率暴涨 × 同期分手/失眠 → 候选认知），互为镜像；
- 每次交互结束**双路提交**（85-2 第五支柱、R5 §八）。

**实现层表态**：同库不同 subject（或等价可查询隔离）；**禁止两个互不相通的库**——否则"交叉发现"与"AI 自身镜面日总结"（85-2）无法实现。

**依据**：第 30/31/32/32-1/32-2 条、第 110 条契约 11、R5 §八；实测：M0 参考实现为单一 SQLite store。
**置信度**：**高**（契约级）；**中**（存储形态属工程选择）。

## Q9 · 绝对硬边界

**清单**（每条附"判错成本"，与 Q2 规则自洽）：
1. 人身安全首动作：首动作前 0 LLM/World、≤50ms、不可被冷却/预算/策略屏蔽（成本：一条命，不可恢复）；
2. 权限身份边界：AI 会话不得自我扩权，越权 fail-closed（成本：越权即系统失守）；
3. 历史与证据不可静默篡改：append-only + 引用锁 + 时间单向；回溯标注只能走 RetrospectiveAnnotation 追加（成本：真相不可重建）；
4. 物理删除唯一路径：33-6，LLM 无直删权（成本：误删不可逆）；
5. 零误触 = 因果律：无 epoch 即断电，`false_playback_without_epoch=0`（成本：一次误播即信任崩盘）;
6. fail-closed 总原则：门禁不过不投放；拿不准宁可沉默（这是 1~5 的元规则）。

**依据**：第 78/82/93 条、25-2、31-3、33-6、85-4、85-6 #5；实测：`runtime_policy.json` hard_rules 7 条 = 本清单的机器可读投影（本日 285 项实测全绿，含 policy 门禁）。
**置信度**：**高**（与 C1-Q9 高度收敛；我多了"判错成本"标注法与第 5 条单列）。

## Q12 · 只保留 5 条宪法，保哪 5 条

1. **唯一时间轴 + 历史不可倒写**（真相可追）；
2. **事实与认知分离 + 认知可翻案**（不僵化、能进化、可认错）；
3. **AI 是唯一操作员，高阶认知主权归 AI**（这是 AIOS 的**名分**——C 的表述是"程序不得做语义裁决"，同一件事的正面/反面说法，我取正面：没有它就不是 AIOS）；
4. **全链条可审计**：认知、删除、行动、沉默，都能回答"依据是什么"（信任的底线——用户不敢信，"帮助"不成立）；
5. **帮助而非记录，帮助的形式包括沉默**（把 C 的"帮助而非打扰"与第 4 条"帮助不是记录"合并为一：灵魂是帮助，边界是沉默，第 4/5/80/96/14-2 条的共同内核）。

**置信度**：**中高**。
