# AIOS 2.0 (新主线)

> **当前分支**：`aios-2.0`（AIOS 2.0 唯一开发主线）  
> **历史分支状态**：AIOS 1.0 全量项目已冻结封存至 `aios` 分支（Tag: `v1.0-frozen`）  
> **最高约束**：《AIOS核心系统宪法v2.0》

---

## 1. 项目定位与目标

第一阶段目标：
做一个可以**持续运行**、**主动发现帮助机会**、**能够纠错**的 AIOS Core；使用同一个虚拟人的长期生活来验证它。  
系统架构、认知工作台和测试环境一体化设计，避免最后仅停留在“数据库存好了、模型回答了”。

第一阶段交付范围：
**共同世界运行时 + AI认知工作台 + 任务与唤醒调度 + 会话执行器 + 纠错与成长 + 虚拟世界评估系统**。  
（注：Linux 桌面、硬件驱动、实体手环、应用商店等暂不进入本阶段关键路径）。
