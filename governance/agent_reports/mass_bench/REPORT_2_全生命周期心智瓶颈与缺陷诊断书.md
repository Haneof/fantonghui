# 全生命周期心智瓶颈与缺陷诊断书

> 交付物 2/3 · 基于 512 万点全马压测的实证剖析 · 2026-09-16
> 数据底稿：`governance/agent_reports/mass_bench/full_press_report.json`

---

## 1. 总判断

AIOS 3.0 心智管线的**认知语义层已经相当健壮**（8 阶段全绿、五铁律全守、
穿透断裂率 0.0%），真正的瓶颈不在"对不对"，而在"贵不贵"。按 Token、
I/O、失真三个维度排序，病灶集中在**摄入层与检索层的实现策略**，
而非宪法架构本身。

## 2. 逐环节诊断（按严重度降序）

### 2.1 【最大 I/O 热点】多关键词共现拓扑召回：O(N) 全表扫描

- **实测**：34 万记录库上单次路径 C 查询 P50 893ms / P95 942ms。
- **根因**：`MultidimensionalSearchEngine._topological_drill` 对每条候选
  记录做关键词共现判定时遍历全库（`for rid in self._records`），共现
  约束靠逐条哈希集合比对。关键词倒排（`_by_keyword`）已存在但只服务
  路径 B，路径 C 没有把 AND 下推到倒排层求交集。
- **为什么现有实现不完美**：路径 B→C 的演进补丁式叠加——B 用倒排但无
  共现、C 有共现但放弃了倒排。两条路径各自拿了半个最优解。
- **代价推演**：若认知库到达千万记录（10 年全模态），单查 28s，8 轮
  复检制直接失速；这是全系统第一个会"老"的部件。
- **对症**：TP-003《倒排共现索引》——查询期先按各关键词取倒排链
  求最小集交集，再仅对交集做正文共现复核；复杂度从 O(N) 降到
  O(Σ|倒排链|)。预期 34 万库单查 <5ms（见《ToolProposal 报告》§3）。

### 2.2 【最大 Token 消耗】阶段1 摄入的"金字塔前"上下文装配

- **实测**：摄入 26.1s / 全程占比 44%，是单一最耗时阶段。其 Token 代价
  不在压缩比（15.1× 已达标），而在**每日复盘的裁判调用面**：每切片组
  每日 1 次复盘 = 3 年 2,250 次裁判调用；若每次复盘真实携带当日原始
  摘要（音频转写 + 短信 + Caption 清单），单日输入 2~4k Token，
  全马 900 万+ Token——这是全生命周期里最贵的一笔。
- **根因**：复盘粒度绑定了"自然日"，而噪声占比 78% 的日子里，裁判
  大部分算力花在重复模式（同一句叫卖、同一类广告）上。
- **对症**：(a) **噪声指纹缓存**——对高频重复噪声模板做 LRU 指纹去重，
  命中即 0 Token 裁决（预计砍掉 60~75% 复盘输入）；(b) **分层复盘**——
  先用 0 Token 机械词典粗筛，仅"灰色带"样本（既非明确噪声也非明确
  证据，实测约 35%）升级大模型裁决。两者叠加，复盘 Token 预算可从
  900 万压到 <200 万。

### 2.3 【最易失真】金字塔聚合的主题漂移

- **实测**：`_aggregate_conclusion` 的"主线"字段从子节点结论里抽
  高频词。三级聚合后（周→月→季），高频词被"日常"这类骨架词霸榜
  （骨架流每天 3 条 × 全年），剧情主线词在季报以上层级被稀释。
- **后果**：年总结的"主线"可能失真——不是错误结论，而是**代表性
  不足**：用户回头看年度总结，看到的主题权重不等于真实人生权重。
- **对症**：主题词 IDF 加权（骨架词"日常/运动/心率"按全域文档频率
  降权，剧情词升权）；或主题词白名单分层（生理骨架词只在日/周层
  展示，月以上只聚合事件层主题）。

### 2.4 【内存】原始层全量驻留：1,668MB 峰值

- **实测**：512 万点 RawSample + 34 万 pydantic MindRecord 同进程驻留。
- **根因**：压测编排为"一次生成、全量贯穿"的批处理模式；原始层
  （RawSample）在摄入完成后仍被世界对象持有。
- **对症**：摄入管线改**日批流式**——按天生成→摄入→释放，仅保留
  清洗后记录与卷宗；预计峰值 <400MB。这不改变任何语义断言
  （卷宗对照仍逐条进行），只是编排顺序问题。

### 2.5 【结构缺陷已修】四例（压测当场抓获）

| 缺陷 | 危害 | 修复 |
|---|---|---|
| 声纹汉明阈值不随维度定标 | 77→114 碎簇，P 编号爆炸 | 阈值定标 14/32 + 收口归并 |
| 复盘词典漏配家庭/商务原话 | 证据留存 82%（违铁律4） | 词典补全，召回 100% |
| 共振链式聚簇 | 全年信号并成 1 巨簇 | 锚定窗口切分 |
| 每日 purge 全量扫描 | O(天数×帧数) ≈ 分钟级 | 周期批量 + 淘汰重存审计 |

### 2.6 【认知抽象风险】事件生命周期与维度门槛的"配额语义"分叉

- 观察：事件层（REVISED/SPLIT 不限次、仅 STALE 联动）与维度层
  （每日反思配额 1、30 天试用）的克制强度不一致。事件密集期
  （合伙纠纷 3 个月）会产生大量锚点修订，下游复核队列可能积压。
- 判断：这在当前规模（8 锚、2 下游）无害，但千事件级世界里
  复核队列需要优先级（p0 证据链 > 日常事件）与合并策略，
  否则复核本身成为新噪声源。

## 3. 什么已经足够好（不需要动的部分）

- **金字塔无损穿透**：0.1ms、断裂率 0.0%——指针化设计完全达标；
- **P0 硬旁路**：0.08ms / 0 LLM，结构上"世界模型让路"的物理保证
  （调度器无 LLM 调用点）是教科书级实现；
- **单跳隔离**：SHA-256 不变 + 标记数==一级下游数 + 0 LLM，算力雪崩
  在结构上不可能；
- **铁律4 的物理删除审计**：`bytes_freed` 真实释放量 + 幂等粉碎 +
  审计留痕，三层防线严密。
