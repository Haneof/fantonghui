## 冻结契约

ObjectRef：

revision=N = PINNED VERSION REF
- 显式钉住特定版本，不漂移
- get_payload(object_id, revision=N)必须返回该版本
- 不得fallback到最新
- 不存在exact revision => NOT_FOUND

revision=None = FLOATING / LATEST-VISIBLE NAVIGATION REF
- 浮动引用，导航到调用者可见的最新版本
- 仅当调用者learned_at >= target某个版本的learned_at时可见

SourceRef：

具有相同版本语义，并保留source_locator。
- revision=None floating
- revision=N pinned
- source_locator必须保存

通用引用知识边界：

target.learned_at 必须 <= referencing_object.learned_at
- 通用边界适用于所有ObjectRef/SourceRef
- 按UTC instant比较，不得直接aware datetime比较（DST fold陷阱）
- DB canonical UTC via as_utc
- pending same-transaction按UTC instant ordering

pending比较：

按UTC instant，as_utc(referencing) >= as_utc(target)才允许。

DB比较：

canonical UTC via time.as_utc, require_aware, DST instant ordering via fold.

future-hidden与missing：

统一NOT_FOUND，不得泄露未来payload、learned_at等信息。
- code = NOT_FOUND
- context: referenced_object_id, referenced_revision, reason=reference_not_visible_or_missing
- serialized_error不得包含canary FUTURE_SECRET_8848/11:00/learned_at/payload
- R09 PASS canary strict

同事务对象：

允许合法互相引用。
- 同事务内两个对象互相引用，若learned_at满足边界，允许

同事务未来引用：

整个事务拒绝。
- 若同事务中A引用B但B.learned_at > A.learned_at，整个事务NOT_FOUND rollback
