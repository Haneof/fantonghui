# AIOS 总体架构 V1.4-r3.1 增补 —— 基础世界数据与高阶认知维度

## 1. 数据与认知分层

AIOS 的世界运行时采用“基础数据优先、统一认知向上”的结构：

```text
Source / Reality
      ↓
Foundational World Data
      ↓
Parallel Dimension Projection / Association
      ↓
Unified AI Cognition
      ↓
Higher-Order Cognitive Dimensions
      ↓
Summary / Trend / Prediction / Action
```

基础世界数据包括用户对话、消费记录、学习应用记录、位置、传感器、设备、环境以及其他现实或数字来源产生的数据。

关键边界：

- Source 是数据来源，不等于 Dimension。
- Foundational Data 是世界事实承载层，不要求先经过 AI 总结。
- Dimension 是对共同世界数据的长期认知坐标/观察线，不是独立记忆数据库。
- Cognition 是 AI 对基础数据及其关系形成的理解。
- Summary 是派生认知，不覆盖基础数据。

## 2. 共享基础数据

一个基础数据对象可以同时被多个维度引用或投影，而不复制底层事实：

```text
                     Foundational Data
                            │
          ┌─────────────────┼─────────────────┐
          ↓                 ↓                 ↓
        时间              工作              学习
          │                 │                 │
          └─────────────────┼─────────────────┘
                            ↓
                    Unified AI Cognition
```

因此维度不是“每个维度各自保存一份 AI 总结”。AI 应能够跨维度统一读取和重新理解共同世界数据。

## 3. 高阶认知维度

在平行独立维度之上，AI 可以动态形成高阶认知维度。

```text
数学 ───────┐
英语 ───────┼──→ 抽象 / 统一认知 → 个人能力
编程 ───────┘
```

数学、英语、编程仍保持独立并持续生长；“个人能力”只是 AI 从它们以及相关基础数据中发现的更高层长期认知结构。

高阶维度不是父节点，不拥有低阶维度，也不取代低阶维度。

## 4. 多层、交叉、非树状抽象

高阶维度可以继续参与更高层抽象，也可以与其他维度交叉形成不同方向的认知：

```text
数学 ─────┐          英语 ─────┐
编程 ─────┼→ 技术能力          ├→ 沟通能力
工作 ─────┘          社交 ─────┘
              \      /
               \    /
                ↓  ↓
               个人能力
```

以上仅为机制示意。实际系统不得把这些名称、组合、层级或关系写死。

系统只提供形成、查询、演化、关联、合并、拆分、重组、弱化和停用高阶维度的能力，由 AI 根据长期证据和认知价值决定实际结构。

## 5. 时间尺度与高阶维度

任何维度，包括高阶维度，都可以形成自己的时间尺度总结，但不同维度不要求使用相同粒度：

```text
基础数据
   ↓
日 / 周 / 月 / 季 / 半年 / 年 / 多年
   ↓
维度长期认知
```

时间聚合是认知能力，不是固定 Schema。高阶维度的形成也不要求固定时间跨度或固定数据数量。

## 6. AIOS App 边界

AIOS 能力应用产生的数据进入共同基础世界，不建立自己的长期 Memory / Personality / World Model。

例如教育应用记录数学练习、英语学习、编程实践，这些首先是基础世界数据；AI 可以在统一世界认知中形成“学习能力”“个人能力”等高阶结构，而不是让教育应用自行建立一套平行人生记忆系统。

## 7. 架构不变量

> **世界数据只有一个共同事实基础；维度可以有很多；认知可以不断向上抽象。**

> **维度之间可以独立存在，也可以被 AI 抽象成更高阶维度；抽象不是父子分类。**

> **AIOS 不预定义最终维度树，而提供动态生成认知层次的能力。**

> **高阶认知可被重新理解，但不能破坏其所依据的基础世界数据。**
