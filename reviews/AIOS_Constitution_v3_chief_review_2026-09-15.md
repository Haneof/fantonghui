## 0. 总览判定

宪法 v3.0 是一份**认知野心远超工程护栏**的文档。十项机制中约六项有扎实的理论/工程基础且与 M0 已冻结契约天然衔接（双世界、条件任务、看板、端侧语义化、震动先导 FSM、三级流水线骨架）；但有四项以**隐喻代替规约**（认知反向传播、突触共振自动生维、5D 滑动条、1 秒首字"绝对"承诺），若按字面进入开发任务，会在 6~12 个月的长周期运行中产生**记忆污染、维度爆炸、修正雪崩**三类退化。本报告逐维审查并给出可落地的强制修补。

## 一、认知架构与理论自洽性审查

### 1.1 双平行世界 + 认知反向传播

**自洽部分。** 将"关于世界的信念"与"关于自身心智状态的记录"（羁绊、承诺、负重心智、自省）分离，与认知科学中**语义记忆 vs 自我参照/自传体记忆 + 元认知**的划分同构，也是相对 MemGPT 等扁平记忆体系的实质进步。仓库 M0 契约已为此铺好地基：`Claim`（claimant≠subject、FACT≠truth）、`EvidenceSet` 一等对象、append-only revision——AI 自身世界完全可以作为另一组 claimant=AI 的 Claim 集合落地，无需新存储模型。

**不自洽部分（严厉指出）。** "内心复盘得到的洞察沿突触反向投射回物理曲线与现实事件"——这句是**隐喻，不是写入协议**。若自省产物被写回世界模型且与观察同权，就构成**认识论洗钱（epistemic laundering）**：

- 推论 A（置信 0.6）→ 自省得推论 B（0.6×0.6=0.36 的真实置信）→ 反向投射后 B 以"世界事实"身份参与下一轮推理，置信被隐式重置为高值；
- 多轮后， agent 的低置信幻想沉淀为"两年来的既定事实"，且因 append-only 而**永久驻留**。

这是比 RAG 幻觉更危险的失败模式：RAG 幻觉在检索时可被原文反驳，而沉淀型污染会**销毁反驳依据**（见 3.4 端侧删除）。

**强制修补（P0）。** 反向传播只能以 `provenance_class ∈ {observation, external, inference, introspection}` 标记写入，且：
1. introspection/inference 类写入必须携带**折扣后置信**（乘法链，不得重置）；
2. 此类 claim 永不得单独升级为 FACT，必须与至少一条 observation/external 证据共现方可提升；
3. 现状契约已有 `confidence: float` 字段（`Claim`/`Relation`/`DimensionDerivation`/`EventAnchor`/`Goal` 均见 `src/aios_core/contracts/models.py`），缺的是 provenance 维度——这是 v3.0 必须补进 M0 契约修订的第一字段。

### 1.2 轴向时间金字塔 + 纵向突触共振

**自洽部分。** 1s→10y 的多尺度沉淀 = 分层时间摘要/物化视图，与分层记忆文献（Generative Agents 的 reflection、时序抽象）一致；它是后文 5D 滑动条唯一可行的性能地基。宪法 2.0 第 91 行"所有维度挂载同一条时间轴"已给金字塔提供了轴向约束，方向正确。

**不自洽部分。** "不同维度在相同时空点共振，自动激发新维度候选"是一个**无预算的生成过程**。没有以下三条，维度数将单调增长直至索引与提示词双双爆炸：

1. 候选上限（并发候选维度 ≤ K）；
2. 晋升阈值（共振计数 ≥ N 且跨源证据 ≥ 2 才允许从 `DimensionDerivation` 晋升为 `DimensionDefinition`）；
3. 退场机制（连续 T 无读取/无共振的维度降级归档）。

M0-011 已冻结 Dimension 三层契约且 `DimensionDerivation.confidence` 天然是晋升钩子——**共振机制必须、也只能实现为该契约上的受控状态机，而不是宪法里的自由诗**。

### 1.3 是否真正解决"记忆扁平、上下文爆炸、因果断裂"

- 记忆扁平：**部分解决**。双世界 + 维度拓扑确实把扁平向量库变成了结构化认知图。
- 上下文爆炸：**机制正确**。single-shot 看板 + 1500-token 滑窗把提示词体积上界化；但看板"极简"二字不是规约，必须给出 token 预算（见二.1）。
- 因果断裂：**方向正确但有写入侧风险**。EventAnchor + 因果超链接优于 RAG 的事后猜测；但因果边由后台 LLM 萃取，**萃取错误会变成永久因果记忆**——传统 RAG 检索原文反而没这个病。结论：v3.0 用"读时成本"换了"写时风险"，只有配合 provenance 代数与可修正 revision（M0 已具备 append-only）才成立。

**本节判定：理论自洽性 7/10——骨架自洽，四处隐喻必须规约化。**

## 二、工程落地可行性与资源约束压力测试

### 2.1 Token 算力与延迟（1 秒首字）

逐项拆预算（穿戴端 + 云混合，暖路径）：

| 环节 | 预算 | 依据 |
|---|---|---|
| 震动 FSM 唤醒 + 端侧特征 | ≤50ms | 纯本地 |
| 看板装配（索引读，禁全表扫） | ≤100ms | 条件：看板 ≤2K tokens、读路径全索引 |
| 网络 RTT + 排队（暖连接） | 200~500ms | 冷连接 1~3s，**冷路径必破 1 秒** |
| 模型 TTFT（小 prompt） | 200~400ms | 1500-token 窗 + 2K 看板 ≈ 4K 输入，主流模型可达 |

结论：**"1 秒首字"在暖路径下可行、冷路径下不可行**。把它写进宪法当绝对承诺是错误的；应改写为 SLO：P50≤1s / P95≤2s（暖），冷唤醒明示降级（先震后言）。三级流水线本身（滑窗/异步萃取/按需联想）是正确架构，且**联想回捞必须异步预取、不得进首字关键路径**——宪法目前未写明这一点，属盲区。

条件任务零浪费：正确且可实现，但**触发条件文法必须受限**——只允许可索引谓词（时间窗、场景标签、事件类型、实体 ID），禁止"由 LLM 现场判断是否就绪"的条件进入热路径，否则"杜绝空转"会被条件评估本身吃回去。就绪索引 = 时间轮 + 事件订阅，M0 的 Task/Wake 契约可直接承载。

### 2.2 存储与检索：1 个月 ~ 1 年规模压测

量级估算（单用户）：观察类 ~500 条/日（心率/IMU 批聚合后）、claim ~200 条/日、revision 放大 ×1.2 → **年规模约 25~30 万对象、约 35 万行 revision**。SQLite（WAL、单写者）在此量级完全胜任（数百 MB），M0 追加式存储 + 全局 world revision 的模型正确。瓶颈不在容量，在三处：

1. **多关键词共现检索**：`[妈妈,生日,礼物]` = 三条 posting list 求交。若建有倒排索引（SQLite FTS5 或自建 posting 表），年规模下单查询 <100ms 可行；**若宪法意图是遍历图谱边做共现，则 O(边数) 不可行**。强制：共现走倒排，因果切片走**深度有界**（≤3 跳）的图遍历。
2. **5D 滑动条聚合**：对 30 万行原始事件做在线多维聚合 = 每次滑动数百 ms~秒级，穿戴端不可接受。**唯一可行解：滑动条只读金字塔沉淀层（物化聚合），下钻才分页读原始层**。宪法必须把这句写死，否则该特性在 M2 阶段必死。
3. **写放大**：突发多模态 ingest vs 单写者乐观并发 → VERSION_CONFLICT 风暴。M0-017 已把 busy 映射为 VERSION_CONFLICT、M0-016 有幂等指纹——方向对，v3.0 需补**端侧批提交策略**（如 2s 或 64 条合批）作为宪法条款。

### 2.3 边缘轻量化

- 照片端侧语义化、只存文字：存储账正确（~50 张/日 ×1~2KB ≈ 18MB/年），但**不可逆**——语义化错误无原件可复核。强制：原始图 72h 隔离检疫期后删，声纹同理（30d）。
- 声纹 6 个月冷热淘汰：可行；淘汰必须留**墓碑 + 稳定 ID**（M0-003 稳定 ID 契约已覆盖），否则关系图谱出现悬空引用。
- IMU 存大波形 + 平均线：可行；需明确降采样率与保留窗，否则"杜绝存储爆炸"只是口号。

**本节判定：工程可行性 6/10——所有"可行"都附带上面写死的强制条件；按宪法现稿字面实现则 4/10。**

## 三、系统漏洞、边界盲区与潜在失效模式（Red Teaming）

按严重度排序，给出 触发条件 → 失效机制 → 强制缓解：

| # | 失效模式 | 触发 | 机制 | 强制缓解 |
|---|---|---|---|---|
| R1 | 认识论洗钱 | 自省反向传播常态化 | 低置信推论沉淀为高权事实，自我确证闭环 | provenance 代数 + 折扣置信 + 提升需外部共现（P0） |
| R2 | 修正雪崩 | 推翻两年期假设（"老张是好人"） | 急切全量重算依赖链 → 算力雪崩、写风暴 | **taint-bit + 惰性重算**：只标记污染、读时/定时限额重验；有界优先队列；SLO 化（T 时间内或 N 次读内完成），严禁 eager 全传播（P0） |
| R3 | 维度爆炸 | 共振自动生维无预算 | 维度/索引/看板三爆炸 | 候选上限 + 晋升阈值 + 定期退场（P0） |
| R4 | 噪声沉淀 | 传感器剧烈噪声（运动/故障） | 垃圾锚点逐层沉淀进金字塔全部层 | 置信门槛 + 去抖窗；沉淀层保留来源质量元数据，可整层重沉 |
| R5 | 幻觉沉淀 | 后台萃取 LLM 幻觉 | 假 claim 永久驻留 | 萃取产物初始 status=provisional；提升需共现/用户确认；用户纠正走 append revision |
| R6 | 对话投毒 | "日常对话=第一证据超级母体" | 对抗性/玩笑性对话成为高权证据 | 源信任加权（user 直述 > 转述 > 第三方）；超级母体≠超级权限 |
| R7 | 唤醒重入死循环 | 四步序执行中触发源再唤醒 | 步骤 4 审视触发源 → 新唤醒 → 重入 | 唤醒合并（debounce/coalesce）+ 单飞（single-flight）唤醒令牌 |
| R8 | 写冲突风暴 | 多源并发 ingest 突发 | 单写者乐观并发大量回滚 | 端侧合批 + 指数退避（M0 已具幂等，可安全重试） |
| R9 | 不可逆丢失 | 端侧原件按策略删除 | 语义化错误无法复核 | 原始数据检疫 TTL（图 72h / 声纹 30d） |
| R10 | 金字塔失效级联 | 迟到数据/纠正到达 | 多层物化视图连环重沉 | 分层失效位 + 后台限速重沉，禁止同步全量重算 |

**最狠的一句**：v3.0 目前对 R1/R2/R3 这三个长周期必现的退化模式**没有任何一条成文规则**——而它们恰恰是"运行一年"这个唯一开发目标的头号杀手。宪法 2.0 的 append-only 提供了修正的*能力*，v3.0 缺的是修正的*算法与预算*。

## 四、与业界主流框架对比

| 对比对象 | 实质差距 | v3.0 优势 | v3.0 仍理想化处 |
|---|---|---|---|
| **MemGPT / Letta** | 分层 memory（core/recall/archival）+ 函数调用换页 | 双世界 + 时间金字塔是更丰富的时序分层；Letta 的 self-block 只是人设文本，不是带承诺/自省的认识论自我 | 反向传播协议未规约化，优势尚停在纸面 |
| **AutoGPT** | 循环执行器，记忆浅、token 浪费臭名昭著 | 条件触发零浪费执行是对其盲-loop 的直接否定，代际正确 | 条件文法不受限则优势自毁 |
| **LangGraph** | 编排 DSL，非记忆架构 | 不在同一层，AIOS 需要此类执行层而非竞争 | 宪法未承认需要外部编排层，有 reinvent 风险 |
| **Generative Agents（斯坦福小镇）** | recency/importance/relevance 检索 + reflection，最接近的学术先祖 | 跨维共振与双世界是其没有的；且 GA 的 importance 打分已被证明漂移 noisy，v3.0 若不做晋升/退场预算会重蹈覆辙 | 共振机制目前比 GA 更不设防 |
| **Humane AI Pin** | 硬件形态先烈：always-on 多模态 → 热/电量/隐私/延迟四杀 | 震动先导 FSM + 零 UI 黑盒静默是对 Humane 失败模式的精准回应 | "1 秒首字"若写成绝对承诺，就是在重复 Humane 的云延迟之罪 |

**代际优势总结**：一等公民的认识论（Claim/Evidence/provenance）、append-only 可修正真值、自我世界、条件执行——这四点是真实的架构领先。**过度理想化总结**：反向传播、共振生维、5D 在线聚合、绝对延迟承诺——这四点是未经规约的赌注。

## 五、综合评分与 Top-3 强制落地建议

| 维度 | 分 | 理由 |
|---|---|---|
| 1. 架构前瞻性与理论深度 | **8** | 双世界/认识论一等公民/条件执行是真代际进步 |
| 2. 工程落地与实现可行性 | **6** | 六项可直接落在 M0/M1 契约上；四项需先规约化否则不可实现 |
| 3. 穿戴物理形态契合度 | **7** | 震动 FSM、端侧语义化、零 UI 默认高度契合；延迟条款需 SLO 化 |
| 4. 规则完备性与防退化能力 | **5** | 对 R1/R2/R3 长周期退化无成文规则——这是最短板 |

### Top-3 必须立即进入开发任务的落地项

1. **P0 · provenance 与置信代数入宪入契约**：`Claim`/`EvidenceSet` 增加 `provenance_class` 与折扣置信规则；introspection 反向投射不得重置置信、不得单独升 FACT。落点：M0-008/M0-009 契约修订 + 专项回归测试（可编号 M0-023）。理由：没有它，双世界 + 反向传播 = 制度化自我洗脑。
2. **P0 · 修正传播改为 taint-bit 惰性重算协议**：推翻旧信念只标记依赖链为 tainted，读时/限额后台重验；定义 SLO 与有界队列；金字塔层带失效位限速重沉。落点：M0-018/M0-020 扩展 + M1 查询层实现。理由：这是"运行一年"目标下唯一的防雪崩闸。
3. **P0 · 维度预算法 + 检索物化纪律**：共振候选上限/晋升阈值/退场 TTL 落在 `DimensionDerivation→DimensionDefinition` 状态机上（M0-011 已有 confidence 钩子）；共现检索强制倒排索引、图遍历 ≤3 跳；5D 滑动条强制只读沉淀层、下钻分页。落点：M1-010~014 查询与索引任务的验收标准明文写入。理由：无预算的生成式架构必在月尺度爆炸。
