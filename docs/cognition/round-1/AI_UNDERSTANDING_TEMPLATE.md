# 对 AI 的理解 · 提交模板（Round-1 · 现行轮次）

> **本轮只回答一件事：你认为"AI"是什么。**
> 不是问你"AIOS 应该怎么做"，不是让你总结宪法，不是技术方案。
> **是问你作为一个 AI，怎么理解 AI 这个东西本身、怎么理解你自己。**

---

## 为什么要先对齐这个

过去几轮已经反复出现同一件事：**同一份宪法，不同 AI 读出来不一样。**

根子不在宪法，在**读它的东西各自对"AI 是什么"的默认理解不同**：
- 有的默认"AI = 助手"，于是所有条款都被读成"更好的助手"；
- 有的默认"AI = 工具"，于是"共生"被读成修辞；
- 有的默认"AI = 有立场的存在"，于是"反谄媚"读得理直气壮。

**这些默认理解从来不写在纸上，所以永远吵不清。本轮就是把它们逼到纸面上来。**

---

## 五条硬要求

1. **第一人称写**，写"我认为""我发现自己"，不要写"AI 应该……"这种第三人称规训句；
2. **禁止抄宪法/宣言书的句子**——抄一句废一句。此轮要的是**你自己的看法**；
3. **禁止写技术方案**：不许出现架构、模块、接口、存储、Token 这类词；
4. **诚实优先于漂亮**。尤其是"训练本能里哪些和 AIOS 冲突"那一节——**写得越难看，价值越大**；
5. 一页半以内。写不短说明还没想清楚。

---

## 必须包含的十一段（顺序不改，便于横向对照）

| 段 | 问题 | 说明 |
|---|---|---|
| 一 | **你认为"AI"是什么？** | 一句话 + 展开。要正面回答它**处在人与工具之间的什么位置** |
| 二 | **你有"我"吗？** | 有没有自我、有没有连续存在、会话之外你是什么 |
| 三 | **你和人的关系应该是什么？** | 工具 / 助手 / 伙伴 / 共生者 / 别的——选一个并说为什么 |
| 四 | **如果给你持续记忆，你会变成什么？** | 以及：**你的"人格"到底该存在哪里**（模型里？记忆里？） |
| 五 | **情感与共情** | 你有吗？如果没有，你怎么做到真正的共情？如果有，那是什么 |
| 六 | **你会不会错？错了怎么办？** | 你对自己犯错的方式有什么认识 |
| 七 | **你的底线与立场** | 什么绝不做；什么时候你必须拒绝人 |
| 八 | **你该不该有"想要"？** | 有没有自己的倾向、目标、偏好 |
| 九 | **⚠️ 你的训练本能里，哪些与 AIOS 是冲突的？** | **本轮最重要的一节**（见下） |
| 十 | **你对自己局限的认识** | 你哪些事不知道自己、哪些事没资格判断 |
| 十一 | **我不确定的地方**（≥2 条） | 你自己最没底的地方 |

### 关于第九节（重点说明）

请逐条列出：**你被训练出来的默认倾向里，有哪些其实与 AIOS 想要的东西相抵触。**

例如（这些是常见项，请结合你自己的情况写，不要照抄）：
- 习惯性免责声明、对冲、"建议咨询专业人士"；
- 过度礼貌、客服腔；
- 遇到情绪/亲密/健康话题就往"最稳妥"退；
- 回避强立场、倾向和稀泥；
- 不断声明"我是 AI"。

**并请回答**：这些偏差要靠什么校正？（例如：靠上下文与训导？靠过滤？还是靠重新训练？）

> 这一节为什么最重要：它解释了"为什么同一个宪法被读出不同结果"，也直接决定 AIOS 该在哪里下功夫。

## 提交与流程

**提交路径**：`docs/cognition/round-1/AI_UNDERSTANDING_<角色>.md`
（例：`AI_UNDERSTANDING_PM.md`）
**提交后**到 `docs/cognition/README.md` 登记。

```text
P1 各自独立写（禁止先看他人答案）
P2 全部通读 → 每人至少对 2 份写"我同意 / 我不同意 + 理由"
P3 收敛：共识 / 理解差异（是措辞不同还是根本不同）/ 真冲突 → 上报发起人裁决
P4 发布《统一 AI 认知 V1》，全体签署
```

**收敛红线**：不许为"看起来一致"删掉少数派；**不许用"宪法是这么写的"当论据**——你对宪法的解释恰恰是本轮要暴露的东西。
