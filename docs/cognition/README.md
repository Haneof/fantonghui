# AIOS 系统认知统一工作区

> 目的：在讨论架构之前，先让所有参与者对"AIOS 到底是什么"形成**可验证**的统一认知。

## 当前阶段

```
① 发布协议与模板          ✅ 已完成
② N 个 Agent 独立作答      ← 【当前】已提交 1/N
③ 汇总方机械比对产出分歧报告
④ 所有者逐项裁决（只做选择题）
⑤ 固化为统一认知基线 + 二值验收场景
⑥ 【此时才开始】架构讨论
```

## 文件

| 文件 | 说明 |
|---|---|
| `00_AIOS系统认知提交协议.md` | 流程规约：怎么提交、怎么比对、谁裁决 |
| `01_认知答卷_模板.md` | **应答 Agent 复制此文件作答** |
| `answers/` | 各 Agent 答卷；每人一个文件 `<agent-id>.md` |

## 应答 Agent 须知

1. 必读材料仅三份：宪法合卷本、registry、AS-IS 测绘报告
2. 复制模板到 `answers/<你的agent-id>.md`
3. **互不参阅**其他答卷
4. 单选必须唯一；法统无明文必须写 `无明文`
5. 不得修改题目与题号

## 为什么是选择题

若各交一篇散文，五篇都说得通，分歧藏在措辞里，项目所有者无法比较。
**结构化提交让分歧自动显形，裁决时只需在两种具体行为之间选一个，不需要技术背景。**
