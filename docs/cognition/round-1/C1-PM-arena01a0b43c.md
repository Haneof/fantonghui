## Q1 · AIOS 是什么 / 不是什么

**结论**：AIOS 是一个**由 AI 亲自操盘的多维共生心智运行底座**：确定性程序负责让"世界"可信、可查、可回滚、可审计；AI 负责理解、判断、联想、分寸、是否开口、是否行动。它的产品形态不是功能集合，而是**一个越来越懂"这一个具体的人"的随身存在**。

**不是什么**：
1. **不是"带 AI 功能的操作系统"**——AI 不是被操作系统调度的一个模块，AI 是操作员；
2. **不是 RAG 聊天壳**（检索→塞 prompt→回答，R5 第十一节明文禁止退化为这个）；
3. **不是规则引擎/自动化助手**——不用关键词、词典、固定状态机替 AI 做语义判断；
4. **不是用户画像 + 推荐系统**——它记录的是"发生过什么 + 我当时怎么理解 + 后来怎么改判"，不是标签表；
5. **不是"用 AI 做数据处理"的流水线**——清洗只是入口，认知闭环才是主体。

**依据**：`AIOS核心系统宪法v3.0.md` 第一条；宣言书全文；R5 第八十五条之三（三层法统、禁止 RAG 外壳）。
**置信度**：**高**。

## Q2 · 谁是最终决策者：程序与 AI 的边界

**我的判定规则（三条，可操作）**：

1. **不可逆 / 涉人身安全的动作 → 确定性程序执行，AI 只能提出意图**。
   （物理删除、权限变更、外呼 120、骨传导通道断电，都属此类）
2. **语义判断 → 一律归 AI**；程序不得用关键词、阈值、正则、固定状态机产出**语义结论**（"用户失恋了""这事很重要"）。
3. **判定测试题**（对任何新增代码问一句）：
   > 这段代码是在**给 AI 提供可靠工具**，还是在**偷偷替 AI 做本该它做的判断**？
   > 若是后者，且不属于安全/物理约束 → **架构方向错误**（R5 第二节原文即此意）。

**我再补一条细则（这是我加的，不是宪法原文）**：
> **程序可以做"候选筛选"，不可以做"最终裁决"。**
> 且筛选必须满足两个条件：① 结果可解释（给出 `hit_reasons`）；② **AI 可推翻**（AI 有不可剥夺的再查询权，前置召回不得垄断记忆入口）。

**边界模糊地带我怎么处理**：一律**往"给 AI 工具"这一侧靠**；只有在"不可逆、涉安全、涉权限"三类上才允许程序抢跑，并且必须留审计。**拿不准时，宁可让 AI 多判断一次，也不要让程序替它判断。**

**依据**：R5 第二/三/四节；ADJ-001（Step-0 是确定性机械闸，先于心智）；ADJ-006（检索只给候选）。
**置信度**：**高**（规则本身是宪法明文）；但**具体划线位置**（例如前置召回该预取几条、哪些算"必要安全"）**我只给中**——因为宪法没有给出判定机制。

## Q3 · 系统的身体边界（端 / 云 / App / 设备）

**结论**：

| 层 | 承担 | 绝对不做 |
|---|---|---|
| **端侧（手环 / 手机）** | 采样、降噪、ASR 转写、声纹指纹、图像语义化、格式化、FSM 状态机、震动/骨传导执行、安全硬旁路首动作 | 复杂语义判断（情绪/压力/事件/关系/意图） |
| **云侧大模型** | 理解、判断、归因、总结、分寸、生成、写回决策 | 直连硬件做物理动作；越过权限 |
| **App** | 定义专业领域/目标/工具/界面，产生领域数据 | **拥有独立用户世界或独立 AI**（必须是同一个 AI 进不同专业场所） |
| **外部设备** | 传感器与执行器 | 参与认知 |

**什么绝对不能下放**：
- **人身安全首动作**（摔倒/心律失常/自杀危机）：必须**端侧本地确定性**执行，不依赖网络、**首个硬件安全动作前不得调用 LLM / World**（首动作完成后才可进入受控 `EmergencyDialogueJudge` 认知研判）；
- 身份/权限/历史写入的原子性与引用完整性；
- 骨传导通道的**无先导震动即断电**（零误触是因果律，不是策略）。

**依据**：第三十三条（端侧轻量化摄入）、第七十八条（硬件级安全响应）、第九十八条之一（FSM 零误触）、第一百零四条之一（三层 UI）、第一百零五/一百零六条（模型只是算力、禁本地小模型做复杂语义）；附录 D 裁决第 5 条。
**置信度**：**高**。

## Q4 · 数据底座的最小不变量（动了就崩）

1. **唯一全局时间轴** + **三类时间分离**（occurred / learned / recorded）；
2. **稳定 ID + append-only 版本**：历史**不可倒写**，修正靠"新增 / 撤回 / 标注"，不靠覆盖；
3. **物理事实（Observation）与主观认知（Claim）严格分离**，Claim 可被翻案（`retracted`）、可被反证挂载；
4. **引用完整性**：任何高层认知都必须能穿透到原始证据，**不许断链**；
5. **删除只有受控路径**：墓碑软删 → 引用锁/legal hold 机械审计 → 物理粉碎；**LLM 无直删权**，且必留 `DeletionLog`；
6. **认知必带来源与置信度**，且置信度属于**具体主张**而非整段话；
7. **双主体共用同一套机制与同一时间轴**（用户世界 / AI 自身世界）；
8. **事务 / 幂等 / 审计回放**：中断可恢复、不重复执行、可回答"当时看到了什么、查了什么、写了什么"。

**依据**：第十六/十七条；第三十五/三十八/四十条；第四十二~四十五条；第二十五条之二（ADJ-004）；第九十三/九十四条；第一百一十条第 1~15 项；R5 第十节（可回放性）。
**置信度**：**高**（第 1~7 条是宪法明文；第 8 条的实现细节我给中）。

## Q5 · 世界对象模型与"维度"到底是什么

**结论**：世界 = **对象 + 引用 + 版本 + 时间**。22 个一等对象（Observation…ToolProposal）构成词汇表；对象之间是**指针网络**，不是树、不是表间外键拷贝（"突触指针，禁止冗余拷贝"）。

**维度是什么——我明确表态**：

> **维度是"可挂载的观察坐标系 + 认知假设"的双层结构**：
> - **定义层（DimensionDefinition）= 假设**：它断言"值得用这个视角持续观察这个人/这件事"；因此它必须有生命周期、有来源、有证据、有反例、可被降级；
> - **投影层（Membership / 派生）= 视图**：数据以成员关系挂载到维度上，是**可重算的投影**，不是数据的第二份拷贝。

**为什么这个表态重要**：如果把维度只当"视图"，那它就是可随时重算的索引，**无需生命周期治理**；如果只当"假设"，那每次查询都要付认知代价。**我主张双层**——这也解释了为什么宪法既要求"维度有候选/试用/活跃生命周期"（假设性），又要求"任意维度任意节点可互联、可重算"（视图性）。

**争议预警**：代码里更接近"曲线/投影"，宪法文字更接近"假设"。**这两者若不在架构层说清，一定会分叉。**

**依据**：第十八~二十四条；第七十二~七十六条（生命周期与防爆炸）；第一百一十条契约 8/9。
**置信度**：**中**（我对自己这个"双层"解释有把握，但**不确定这是否是原作者的本意**——这正是本轮要对照的）。

## Q6 · 记忆如何生长、如何遗忘

**生长路径**：

```text
原始 Observation（对话/体征/账单/图像描述）
   ↓ 多尺度总结金字塔（日→周→月→季→半年→年→3年）
   ↓ 跨维共振 → 候选线索（不是结论）

   ↓ 更大跨度再交织
```

**遗忘 / 删除边界（我理解的宪法立场）**：

- **不遗忘事实，只调整权重与活跃度**；
- **总结是新增观察层，不是压缩替换**；失效是打 `STALE`，不是删；
- 物理删除**只针对"可吊销对象"**（无任何引用的冗余副本；或原始高频波形且其语义化结论已落库）；

- "低频 ≠ 无价值"：关联长期承诺的维度只能降频/休眠，**不得清理**。

## Q7 · 运行闭环（醒来—判断—行动—写回）

```text
【确定性】输入 → 清洗/格式化 → 写 Observation → 机械触发评估（八类机械项）
【确定性】Step-0 四闸：安全硬信号 / 方便度 / 投放信道合法性 / 预算 → OK | QUIET | HARD_BLOCK
【确定性】组装最小 Cockpit：身份与立场 / Wake Reason / 时间与现场 / 会话态 /
           就绪任务 / 关系状态 / 能力表 / 少量高置信候选记忆（附来源指针）
        ─────────────── 以下归 AI ───────────────
【AI】ORIENT（我是谁、为什么醒） → INTERPRET（当前真正发生了什么）
【AI】RECALL? → SEARCH / FOLLOW / COMPARE（可多轮、可变路径、可下钻原话）
【AI】DELIBERATE（结合对"这个人"的理解 + 沟通经验）
【AI】RESPOND / ACT / SILENCE        ← 沉默是一等合法结果
【AI】COMMIT：写回用户世界 + 写回 AI 自身世界（分寸/被接受度/误判/承诺）
【AI】REFLECT?（仅当有认知增量；无增量不得写占位内容）
        ─────────────── 回到确定性 ───────────────
【确定性】落审计（输入/工具调用/写入/结果状态）→ 休眠；中断可恢复
```

**关键标注**：
- **前置召回是确定性加速器，不垄断记忆入口**——AI 必须保有不可剥夺的再查询权；
- **Cockpit 四段是排版顺序（layout），不是思维顺序（network）**；`≥2 次往返才能完成首次响应` 视为违宪；
- **AI 可以自主停止查询**（证据够了）与**自主沉默**（无事可做）。

**依据**：R5 第三/四/五/六/七/八/十节；ADJ-001；ADJ-006；第八十五条之四第六节。
**置信度**：**高**。

## Q8 · 用户世界与 AI 自身世界的关系

**结论**：**同一套对象机制 + 同一条时间轴 + 两个 subject**，而不是两个库、两套机制。

- 用户世界记录"他是什么样的人、发生了什么"；
- AI 自身世界记录"我是谁、我做过什么、被接受还是被拒绝、我错在哪、我承诺了什么、我学会了什么用世界的方法"；
- 二者**交叉发现**（例：用户找 AI 的频率暴涨 × 同期分手/失眠 → 形成候选认知），**互为镜像、互相成就**；
- 每次交互结束是**双路提交（Dual-Commit）**：第一路写用户事实，第二路写"我对这个人的理解"的升华。

**实现层我主张**：同库不同 subject（或等价的可查询隔离），**绝不做成两个互不相通的库**；否则"交叉发现"这条宪法条款无法实现。

**依据**：第三十/三十一/三十二条；第三十二条之一/之二；第一百一十条契约 11；R5 第八节。
**置信度**：**高**（契约级：宪法明文"使用同一对象和时间机制"）；**存储形态中**（同库 vs 分库是工程选择，我倾向同库）。

## Q9 · 绝对硬边界（我会用命守的）

1. **人身安全硬旁路**：摔倒 / 恶性心律失常 / 自杀危机 → 本地确定性优先，**首动作前零 LLM 调用**；**不得被冷却、预算、抑制器、AI 策略屏蔽**；
2. **权限与身份边界**：AI 不得自我扩权；越权即 fail-closed；
3. **历史与证据不可静默篡改**：append-only、引用锁、时间单向；
4. **物理删除唯一路径**：墓碑 → 机械审计 → 受控 Worker → DeletionLog；
5. **隐私与"不暴露后台"**：不向用户暴露认知图谱/画像编辑；不把遥测数据（心率/聊天原文）当台词念；
6. **fail-closed**：不确定时**宁可不出声**，不得对外投放未通过门禁的内容。

**依据**：第七十八条；第八十二条；ADJ-004；第六/十四条之二；R6 第二节 A 类（硬边界 fail-closed）。
**置信度**：**高**。

## Q11 · 我认为还没定义清楚的地方（歧义清单）

**清单**：

1. **"AI 主权"与"确定性前置"的边界缺判定机制**——谁能判"这条阈值算工程参数还是认知策略"？现在靠人读宪法解释 → **必然漂移**；
2. **三层（World / Search / Runtime）的接口契约缺失**——R5 定义了职责，但没定义：谁能写、写什么格式、"候选"的数据结构、读语义（知识截止 / 双透镜）；
3. **验收主体缺失**——1,293 个测试**全是确定性断言**，**没有一个在测"AI 的判断质量"**；"像不像"无人负责；
4. **维度的对象模型**（视图 vs 假设，见 Q5）；
5. **双世界的存储形态**（同库两 subject 还是两库）；
6. **"沉默"是不是一等结果**——宪法反复强调可以沉默，但对象清单里**没有 Silence**，Action/Outcome 是否承载它未定义；
7. **预算（Token/延迟）的归属**——算工程参数（程序可调）还是认知策略（AI 可调）？这直接决定 AI 能否自主决定"多查一次"；
8. **降级不变量缺失**——模型不可用/网络断开时，AIOS 还剩多少"像 AIOS"？宪法没写；
9. **Core 与 App / 设备的分界线**只有原则，没有接口契约；
10. **前置召回 vs 自主 Recall 的仲裁规则**（冲突时谁优先、结果如何合并）；
11. **声纹簇与实体身份的绑定规则**（ADJ-009 给了退役/重识别，但"何时算绑定成立"未定）；
12. **宪法解释权归谁**——今天已经出现"同一句话两种解释"的实例（见下方 X1）。

**最危险的 3 个**：
- **① 第 1 条**：没有它，任何人（人或 AI）都能以"这是工程参数"为名把认知主权偷走；
- **② 第 3 条**：没有它，"做出来的到底是个什么家伙"永远不会有人知道；
- **③ 第 2 条**：没有它，每个模块都会自己发明一套读写约定 → 就是老大说的"东拼西凑"。

**依据**：我对全库的实测（见附录 D）；`CHIEF_DIRECTIVE_20260917`（老大自己已经指出第 3 条）。
**置信度**：**高**（歧义的存在是事实，不是观点；但"最危险 3 个"的排序是我的判断）。

## Q12 · 只保留 5 条宪法，保哪 5 条

1. **唯一时间轴 + 历史不可倒写**（真相可追）；
2. **事实与认知分离、认知可翻案**（不僵化、能进化）；
3. **高阶认知主权归 AI，程序不得做语义裁决**（这是 AIOS 的**名分**——没有它就不是 AIOS）；
4. **一切认知可追溯到证据**（可审计、可复盘、可认错）；
5. **帮助而非打扰 —— 适时、适度、可以沉默**（产品的灵魂）。

**理由**：前 4 条保证"这是一个**可信**的系统"；第 5 条保证"这是一个**对的**系统"。
其余所有条款，都是这 5 条在具体场景下的展开——**丢了这 5 条，其他条款再多也只是零件堆。**

**置信度**：**中高**（这是我的价值排序，不是宪法的原文排序）。
