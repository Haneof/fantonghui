四层漏斗

L0 记录层（已有 = T23）：只记录，不思考。hublinkd 持久化队列 + SQLite，一条不丢。
▼
L1 对比层（本任务核心）：规则引擎 <1ms/条，输出三态 IGNORE 留档 / LOCAL 本地凝缩 / ESCALATE 打包证据叫醒大模型。
身体：个人基线（滚动 7 天静息均值±σ）+ 绝对安全带 + 运动语境豁免；
消费：SQL 求和 + 日/周偏离度（如当日 > 3× 滚动均值）+ 大额绝对阈值 + 行为模式（连续 N 天深夜）；
话语：联系人分级 + 模式规则（上级施压/承诺动词/资金词/关系词）+ 频率突增。
▼
L2 小模型层（可选，默认关闭）：只接 L1 分不清的模糊带（预计 <10%），做判断题式三分类。上不上线由 Regret 数据说话。
▼
L3 大模型层（被动唤醒）：只收证据包——SQL 求和结果 + 基线对比表 + 原始事件 + 触发原因。不做过滤、不做计算。
误报/漏报 → Regret 反馈环 → 阈值自动收紧/放宽（evolutiond 已有对账骨架）。全量触发日志落盘。

关键裁定

裁定理由
个人基线 > 全局固定带心率 65 对基线 55 的人正常、对基线 80 的人异常——固定带只做绝对安全兜底（<40 / >150）
AI 不计算，只读结果千题实测：任何 LLM 做精确求和都会翻车；统计由 memoryd SQL 直出，证据包放现成表格
非对称阈值漏报（真异常没叫）代价 > 误报（多叫一次）——初始偏敏感，Regret 环收紧
本地模型新岗位门控出局；保留小时凝缩 + 格式规整（其及格区：求和 65% / 峰值 78%）
