# 04_apps · 应用软件 / 领域（待开工）

**状态：** 空目录。等 OS 能力系统（abilityd）接口冻结后开工。

## 定位（宪法第七章）

AIOS 上的"应用"= 领域（Domain）：AI 和用户在某个人生领域的长期专注空间。领域不拥有独立 AI、不独立存储记忆，共享同一个大脑与三棵树。

## 与 OS 的接口契约（见 01_os/docs/OS总体架构设计_V0.1.md §12）

- OS 提供：abilityd 能力插件接口（注册/权限/调用）、领域接入规范
- 应用提供：领域知识包格式、领域 UI 需求

## 建议首发领域（待产品决策）

1. **贴身管家**（日程/提醒/IoT 联动）——离宪法"主动服务"最近，风险最低
2. **健康守护**（体征监测/趋势）——发挥手镯传感器优势，与 Safety 协同
3. 社交助手、学习助手等场景包按克劳德5框架 §7 顺序后排

## 红线（宪法级）

- 任何领域不得自带独立记忆存储（违者按原则二否决）
- 金融/执行类能力必须走 decisiond 非对称阈值 + 二次确认
