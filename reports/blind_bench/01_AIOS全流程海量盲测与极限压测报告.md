## 0. 一句话结论

在 **1,131,330 条**原始生活流、五类真实人生切片（创业合伙纠纷 / 大厂通宵心律失常 / 家庭长期矛盾与破冰 /
跨省搬家生活相变 / 慢性病长周期管理）上，八阶段全链路 **9.44 s** 跑完，峰值内存 **112.16 MB**，

五条铁律在**机器可复核**的判据下全部 PASS，且"最烧 I/O 的查询"与"失真最大的抽象"都有明确数字定位。

## 1. 测试口径：为什么这份报告不是"自编自答"

| 纪律 | 落地方式 |
| --- | --- |
| 数据不是手搓的 | 全部原始样本来自 `MassiveSyntheticLifeBench`：一个只依赖标准库与自身数据类的发生器，**内部 0 条断言**（`tests/simulation/test_adversarial_life_bench.py::test_generator_contains_no_assertions_of_its_own` 用 AST 扫描证明），配额、种子、时间轴全部外置 |
| 引擎不是桩 | 八阶段全部走仓库既有运行时：`SQLiteWorldStore`（唯一写入口，BEGIN IMMEDIATE + 修订校验）、`EdgeStreamPurifier`、`PyramidAggregator`、`EventResonanceSynthesizer`、`CognitiveDerivativeGate` / `EvolutionGuard`、`SingleHopCascadeIsolator`、`EvidenceGroundedAdvisor`、`CommunicationStyleGovernor`、`MindOrderManifestLoader`、`CockpitPipeline`、`LightweightConditionalEventEvaluator` |
| 压测台不自己打分 | `blind_bench_harness.py` 内部**零断言**，只产出事实字典；验收判据全部在 `tests/e2e_blind/`（59 项）与 `scripts/run_blind_bench.py` |
| I/O 数字来自外部仪器 | `StorageIOProfiler` 挂在 `aios_core.storage.sqlite_store.sqlite3.connect` 上，按墙钟区间把每条 SQL 归因到阶段；压测台不知道自己被测量，因此行数无法被伪造 |
| 历史不可改由哈希证明 | 阶段五在注入"今日新认知"前后各取一次真值表 SHA-256（`object_revisions` / `world_commits` / `operations`），逐字节比对 |

**原始流配额（scale=1.0）**：IMU 50 Hz 1,050,000 条 · 心率 1 Hz 76,800 条 · 图像帧 540 张 ·
音频切片 1,580 段 · 环境文本 2,410 条 —— 合计 **1,131,330** 条。

## 7. 本轮压测的边界（不吹的诚实说明）

* 这是**单机单进程**压测：并发写入、多用户世界隔离不在本轮范围内；
* 大模型调用是**记账口径**（`ModelCallMeter` 路径级计量），不是真实 API 账单；
* 阶段八看板与对话走的是仓库既有的本地装配引擎，不含网络往返时延；
* 数据为**合成对抗数据**（覆盖五类真实人生切片的结构与噪声形态），不等价于真实用户数据分布。
