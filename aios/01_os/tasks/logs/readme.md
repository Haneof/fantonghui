# 工作日志制度

## 规则

1. 每个任务一份日志：`logs/T0X_log.md`，**谁开发谁写**；指挥官验收后在同一文件追加【验收记录】
2. 条目格式：
   ```
   ## 2026-09-09 02:10 | 总线代理
   - 做了：实现 bus/aios_busd.py（订阅表/通配匹配/bus_stats 落盘）
   - 自测：7899 端口双客户端 round-trip 通过；bus_stats.json 字段正确
   - 遗留：无
   ```
3. **诚实原则**：没做成的事必须写"未完成 + 原因"，禁止粉饰。指挥官验收以实测为准，日志造假 = 直接退回
4. 日志是进度表（schedule.md）的数据源；指挥官汇总后更新看板

## 模板

```markdown
# T0X 工作日志 · <任务名> · <代理名>

## YYYY-MM-DD HH:MM | <代理名>
- 做了：
- 自测：
- 遗留：
```
