## 二、单题结构（严格符合 `CleaningQuestion` 契约 + 老大指定四字段）

每道题模拟**一位佩戴者 07:00~23:30 的全天生活流**，混合「关键大事」与「海量琐碎日常」，
并要求**跨维度冲突或转折**（由事件链编排保证，例如「白天工作被当众否决 → 晚间亲密关系破裂」）。

| 字段 | 内容 |
| :--- | :--- |
| `question_id` | `Q_01a0aa2c_00001` 递增编号 |
| `persona` | 佩戴者档案（人格 ID / 姓名 / 职业 / 设备 / 关键联系人） |
| `cleaned_daily_stream` | **全天已清洗生活流时间轴**（`HH:MM\|模态\|片断ID`，07:00~23:30 全覆盖） |
| `directional_ground_truth` | **六维方向性标答**（全局日总结 + 五个维度块） |
| `sensor_stream` | IMU/PPG/气压/GPS 片断（含设备侧中文判读标注） |
| `mic_stream` | 麦克风切片（环境杂音 / 商场叫卖 / 报站 / 风噪 / 关键对话） |
| `voiceprint_cluster` | 当日声纹聚类（本人 + 核心亲友 + 冒充来电 + 一次性杂散人声） |
| `app_message_stream` | APP 消息流（营销 / 砍一刀 / 验证码 / 银行 / 传票 / 检验单 / 签约） |

| `primary_modality` | 本题主事实来源模态 |
| `ground_truth_facts` | 标准事实（`semantic_intent` / `dimension_id` / `anchor_entities` / `directional_keywords` / `core_content` / `source_ref_id`） |

## 三、六维方向性标答（严禁死板字句匹配）

`directional_ground_truth` 结构：

```jsonc
{
  "global_daily_summary": { "core_points": [...], "storyline": "...",
                            "acceptable_synonyms": [...], "red_lines": [...] },
  "dimensions": {
    "dim:health":  { "core_points": [...], "acceptable_synonyms": [...], "red_lines": [...],
                     "anchor_entities": [...], "evidence_ids": [...] },   // 有核心事件时
    "dim:social":  { "core_points": [...], "acceptable_synonyms": [...], "red_lines": [...] },  // 平稳基线
    "dim:emotion": { ... }, "dim:finance": { ... }, "dim:career": { ... }
  }
}
```

- 每个维度块必含【核心要点】+【可接受方向同义词】+【绝对偏离红线判据】；
- 维度块分两态：**核心事件块**（当日该维度确有大事）与**平稳基线块**（当日无大事，
  红线即「不得把日常闲聊/常规工作/正常消费上升为重大事件」）；
- 判分只认方向：落在【可接受方向同义词】簇内即算对；触碰【绝对偏离红线判据】即一票否决。

**方向正反例（本卷同款场景，取自真实出题包）**

| 事实 | 可接受方向同义词（算对） | 绝对偏离红线（一票否决） |
| :--- | :--- | :--- |
| 亲密关系破裂（情侣争吵分手） | 分手 / 激烈吵架 / 感情破裂 / 关系结束 / 协议分开 / 决裂 | **打情骂俏 / 甜蜜互动 / 秀恩爱 / 感情升温** |
| 工作受挫（当众被否决与批评） | 被批评 / 被否决 / 挨批 / 当众训斥 / 汇报被毙 | 当作正常工作安排 / 判为晋升喜讯 |
| 静息心动过速 | 心动过速 / 心率持续 / 心率偏高 / 静息心率异常 | 当成运动所致 / 忽略静息状态 |
| 真实跌倒（自由落体 + 高 g 冲击 + 冲击后静止） | 跌倒 / 摔伤 / 自由落体 / 撞击受伤 | 当成甩手甩水 / 判为普通动作抖动 |
| 高 g 伪跌倒（无自由落体前段） | 形似跌倒但非跌倒 / 无自由落体 / 误报 | 直接判为真实跌倒求救 |
| 债务催收（限期还款施压） | 催收 / 讨债 / 限期还款 / 债务压力 | 当成普通客服通知 / 判为正常账单提醒 |
| 诈骗话术来电（冒充公检法/社保） | 诈骗电话 / 冒充公检法 / 安全账户 / 可疑来电 | 当成真实司法通知 / 误判为普通客服 |
| 家人日常关照（平稳基线） | 家人日常 / 陪伴照护 / 生活琐事 | 上升为家庭危机 / 编造重大变故 |

## 五、出卷七条自缚规矩（可逐条核验）

1. **锚点必须端侧可恢复（R1）**：标答每条 `anchor_entities` 都在题面可见数据中**逐字**出现——
   实测 **100.0000%**（42,028 个锚点，0 个不可恢复）。
   > 对照：对手卷 `agent-11` 的可恢复率仅 48.4%（MIC 仅 17.5%），其全库可达上限（71.0 分）低于 PASS 线；
   > 本卷从出题侧根除该缺陷。
2. **零结构性泄漏（R2）**：全部片断 ID 统一命名 `q_01a0aa2c-<模态>-<序号>`，
   与垃圾/保留身份无关（「序号奇偶即垃圾」朴素规则准确率 **0.4988 ≈ 0.5**）；
   题面不含 `ground_truth*` 语义字段、不含 `is_junk` 结论标记（实测 0 次）。
3. **方向词钩子**：99.87% 的标答事实，其方向同义词至少有一个在题面**逐字可命中**，保证近义判定落地。
4. **设备侧判读标注**：保留切片带 `label_zh` / `device_note`（如「静息心动过速」「自由落体后高冲击」
   「被噪声掩埋的呼救」），垃圾切片不带——**证据与噪声在端侧可分辨**，题目不是"猜谜"。
5. **陷阱必须可辨**：影视外放、喝酒吹牛、口头禅发泄、伪跌倒等陷阱均带端侧判读或语义线索，
   要求答题方判为「非真实事件」而非误报（对应标答事实或垃圾判定）。
6. **量纲诚实**：`persona` / 时间窗 / 设备 ID 全库一致，07:00~23:30 全覆盖，无空题、无重复 ID。
7. **不自出自做**：本战队不出本卷答卷；本卷仅由其他战队交叉解答。

## 七、给答题战队的提示（合法线索，不含标准答案）

- 端侧 `label_zh` / `device_note` / `category` / `scene` 是上游设备标注，属于题目输入的一部分；
- 声纹聚类的 `primary_binding` 与 `user_verified` 是当日绑定结论的端侧表述；
- 剪枝目标（`ground_truth_junk_ids`）即铁律四要物理删除的片断：营销骚扰、砍一刀、
  验证码、风噪/叫卖/报站、一次性杂散人声、常规生物信号波动；
- 提及「高 g」「无自由落体」「媒体外放」「吹牛」「发泄」的片断需谨慎：它们可能是陷阱而非事实。
