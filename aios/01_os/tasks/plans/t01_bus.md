# T01 事件总线 broker（aios_busd.py）

- 里程碑：M0 · 负责代理：总线代理 · 状态：🔵进行中 · 依赖：契约冻结

## 目标

实现 AIOS 的"内部邮件系统"：一个 TCP broker，所有服务经它收发消息，谁也不许直接连谁。

## 实现方式（规划）

1. TCP 服务器（`socket` + `threading`，每连接一线程），帧格式与主题匹配规则严格按契约 §2
2. 订阅表 `{service: [topics]}`；通配 `#`：订阅主题形如 `evt.#` 时，凡以 `evt.` 开头的发布主题都命中（前缀匹配）；否则精确匹配
3. 转发：`pub` → 查订阅表 → 给每个匹配订阅者发 `evt` 帧（**排除发布者自己**）；`sys.*` 主题只转发给显式订阅了该主题的连接
4. `hb` 帧更新该服务 last_hb；坏 JSON / 未知 `t` → 回 `err` 帧，连接不断
5. 每 1.0s 落盘 `run/bus_stats.json`（契约 §3）；目录不存在则创建
6. Ctrl+C 优雅退出（关闭全部连接）；启动时打印 `BUS LISTEN <host>:<port>`
7. 端口：默认读 `aios_config.json`（可能尚不存在→用缺省 7800），支持 `--port` 命令行覆盖（自测用）
