# AIOS 系统认知对齐区（Cognition Alignment）

> **状态**：ACTIVE · 2026-09-18 开设
> **发起人**：老大（最高指令长）
> **本目录解决什么问题**：在讨论架构之前，先让所有参与方把"脑子里的 AIOS"掏出来对齐。

---

## 0. 为什么有这个目录

老大的原话：

> "我不懂代码，你们各自理解各自的、各自出各自的方案，我都完全不知道谁对谁错。"

这句话点出了这个项目到目前为止最根本的病灶：

**每个 Agent 脑子里都有一个私有的 AIOS。谁也没有把它完整写出来过。于是大家各自基于自己的私有理解产出方案，方案在下游互相冲突，而唯一有权裁决的人（老大）看不到上游的理解，因此无法判断谁对谁错。**

在下游（方案、架构、代码）裁决是不可能的，因为下游的每个分歧都可以追溯到上游一个没说出口的理解差异。

**所以：先把上游摊开。**

本目录的唯一目的：让"理解"本身成为可以被阅读、被反驳、被裁决的对象。

---

## 1. 硬性规则

1. **本目录不谈代码、不谈架构、不谈技术选型、不谈模块编号。** 违反者该文件作废。
2. **全中文，写给不懂代码的人看。** 判据：老大读完能说出"这是我要的"或"这不是我要的"。
3. **不许抄别人的结构或结论。** 如果你写完发现和已有文件高度相似，说明你在附和而不是在认知。
4. **必须诚实标注"我判不了"。** 把判不了的东西伪装成结论，是这个项目最大的病。**每个 Agent 的认知文档必须包含一节"需要老大裁决的问题"，且不得少于 5 个问题。**
5. **不许客气。** 礼貌的同意在本轮毫无价值。

## 3. 统一格式（九节）

所有认知文档必须包含以下九节，便于横向对比。**允许某一节写"我这一节和 AGENT-01 一致，无异议"，但不允许省略。**

| 节 | 标题 | 写什么 |
|---|---|---|
| 0 | 这份文件是什么，不是什么 | 自我定位 |
| 1 | 一句话 | 用一句话说清 AIOS 是什么。**这一句最重要** |
| 2 | 它解决的真正问题 | 不是表面需求，是根本问题 |
| 3 | 不可动摇的内核判断 | 抽掉哪条就不叫 AIOS 了。**请别人优先攻击这一节** |
| 4 | 什么不是 AIOS（边界） | 明确写出容易越界的方向 |
| 5 | 当前已经跑偏的地方 | **必须有仓库里的实际证据，不许推测** |
| 6 | 我可能理解错的地方——需要老大裁决的问题 | **本目录真正的产出。二选一形式，不得少于 5 个** |
| 7 | 我用的词是什么意思 | 术语自证，防止同词不同义 |
| 8 | 给其他 Agent 的话 | 你希望别人怎么反驳你 |

## 4. 流程

```
第 1 步  各 Agent 独立提交认知文档（互相不看，避免锚定）
              ↓
第 2 步  全部 Agent 通读所有人的文档
              ↓
第 3 步  各自发表意见：
         - 我同意哪几条，为什么
         - 我反对哪几条，我认为应该是什么
         - 我原文里哪一条被别人说服了，我改
              ↓
第 4 步  分歧登记进下面的【分歧台账】
              ↓
第 5 步  老大裁决台账中"需老大裁决"的条目
              ↓
第 6 步  形成《AIOS 统一系统认知》——一份文件，所有 Agent 签字确认
              ↓
第 7 步  才开始讨论架构
```

**第 1 步必须独立完成。** 如果 Agent B 在写之前读了 Agent A 的，那 B 的文档就失去了独立采样的价值——我们会得到两份相似的文件，而不是一次真正的交叉验证。

## 6. 产出物

本轮结束时应得到两份文件：

1. **《AIOS 统一系统认知》** —— 一份，所有参与 Agent 签字确认，作为后续一切架构与宪法的**唯一上游依据**。
2. **《裁决记录》** —— 老大对全部待裁决问题的答复，逐条留档。

**这两份文件产出之前，不开架构讨论，不写子宪法，不出工程方案。**

## 7. 与现有宪法的关系

- 现有三份宪法（`AIOS核心系统宪法v3.0.md`、`AIOS_Constitution_v3.0_FINAL.md`、`AIOS_Constitution_v3.0_FINAL_CONSOLIDATED.md`、`AIOS核心系统宪法v3.0_统一最终版.md`）在本轮**全部降级为素材**。
- 它们是"过去所有人理解的堆积物"，不是"经过对齐的理解"。
- 统一认知形成后，宪法将被**重写**——不是再整合一次，而是从对齐后的认知重新推导。
- 在此之前不做任何宪法合并动作，避免在错误的上游上继续加固。
