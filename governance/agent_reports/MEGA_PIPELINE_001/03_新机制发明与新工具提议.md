# 《新机制发明与新工具提议（ToolProposal）》

## TP-001 自适应时序压缩算子 AdaptiveTemporalCompactor

- **能力缺口**：IMU 50Hz 与心率流全量直写死于存储与检索双爆；等间隔死采样
  磨平唯一重要的突变波形（铁律 1/4 交点）。
- **用法样**：心率平稳期塌缩时段均值桶；跌倒/骤升冲击逐拍独立成件（含保护环）。
- **现行局限**：等间隔死采样或无上下文窗口的拍点硬截。
- **接口**：
  - `AdaptiveTemporalCompactor().compact(Sequence[Beat]) -> CompactionPlan`
  - 输出 `buckets`（时段均值塌缩）、`spikes`（突变逐拍含保护环）、
    `compression_ratio`、`stats`（bucket/spike/spill 三账）。
- **预期收益**：实测 24h 心率流压缩比 **160:1**（2881 拍 → 18 记录），
  突变 0 丢失（16 拍独立、IMU 冲击 shock=True 成件）。
- **验证计划**：`tests/e2e/test_tool_proposals.py`（5 件机械断言 + 恒等式
  bucket+spike 拍数==入拍数 的不重不漏闭环）+ S1 阶段联动实测（压测报告 01）。

## TP-002 双透镜虚拟索引投影器 DualLensProjector

- **能力缺口**：AS_KNOWN/ANNOTATED 双视图若为两幅图各建物理索引，双倍存储
  双倍漂移；铁律 2 需要可审计的双视图同源性证明。
- **用法样**：老王案回溯解释一致性审计；当时视野回放取证（AS_KNOWN(t)）。
- **现行局限**：两透镜各自落索引，漂移风险客观存在；缺 SHA-256 指纹审计。
- **接口**：
  - `DualLensProjector().project(payloads, at) -> (LensView, LensView)`
  - `assert_consistent(views)`：两透镜 base_fingerprint 同则过，异则炸。
- **预期收益**：单读面双投影，零存储增量；铁律 2 升级为可执行审计
  （底层事实指纹 SHA-256 同，差异只在注记叠层）。
- **验证计划**：`tests/e2e/test_tool_proposals.py` 透镜组（2 件）+
  S5 阶段联动（双透镜一致性断言过棒，压测报告 01 实录 overlay=1 注记挂载）。

## 连带机制建议（列入下一条赛道，不落本次代码主体）

1. **CoSearch 增量索引合并**：`rebuild()` 内部走 `revisions_after(watermark)`
   delta 铺面（诊断书章节一主欠账，行为面零回归）；
2. **历史审计 chained digest**：对象级 hash 链落 `world_meta`，指纹 O(Δ)；
3. **读面缓存**：同流水线内 `list_payloads()` 快照复用（S1/S5 双扫合并）。
