1. 指挥官发出任务书（tasks/plans/TXX.md）+ 冻结契约（tasks/contracts.md）
2. 代理只在**名下文件**内开发；自测通过后写工作日志（tasks/logs/TXX_log.md）
3. 指挥官逐项验收：文件清单 → 运行实测 → 契约一致性 → 验收标准逐条打勾
4. 验收记录写入 plans/TXX.md 的【验收记录】节；不通过退回并注明缺陷，代理返工
5. 通过后由指挥官同步至 D:\手镯开发\AIOS\01_os\
