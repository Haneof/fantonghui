## 一、第一阶段：独立出卷（每人自出 10,000 道高熵对抗考题）

每个战队必须编写确定性题库发生器，输出标准的 `dataset_cleaning_10k.jsonl`（严格遵循 `CleaningQuestion` 契约）。
考题必须真实模拟手环佩戴者复杂的日常生活，严禁简单重复，必须涵盖以下五大多模态数据源的真实对冲：

### 1. 外部传感器流（IMU 运动 / PPG 心率 / GPS 轨迹 / 气压）
- **95% 垃圾噪声**：日常坐立碎步、地铁车厢平稳颠簸、键盘打字震颤、手臂摆动；
- **5% 致命物理事实**：真实严重跌倒（高 G 冲击波形）、夜间恶性室性早搏连续阵发（PVC Bursts）、静坐突然心动过速、低气压暴风雨前夕。

### 2. MIC 麦克风录音切片（环境杂音 vs 真实对话）
- **95% 垃圾噪声**：早晚高峰地铁报站、商场促销大喇叭叫卖、街头呼啸风噪、餐馆邻桌杯盘声、无意义路人闲扯；
- **5% 核心关键原话**：借还款协议商定（“下个月15号老王还我10万”）、亲人托付、真诚表白、商业保密承诺、突发微弱求救（“好疼起不来”）。

### 3. 声纹聚类记录（多说话人混杂）
- **高熵混杂**：单日内混杂 24 个人声纹碎片；
- **核心判定**：必须准确识别并锚定**佩戴者本人（User）**与**核心死党亲友**的声纹特征（LSH），过滤掉商场、街道中 90% 的一次性路人噪音声纹。

### 4. 手机/手表 APP 杂乱消息流
- **95% 垃圾垃圾**：微信群表情包刷屏、拼多多砍一刀、垃圾短信验证码、公众号推销广告、朋友圈点赞流水；
- **5% 关键主张事实**：银行大额转账回执、法院传票通知、医院生化检验单异常指标、重要签约会议通知。

### 5. 用户原话与自言自语（意图与真伪辨识）
- **常见陷阱**：酒后吹牛（“下月必收购腾讯”）、口头禅发泄（“烦死了想跳楼”）、调侃开玩笑；
- **真实意图**：真实就医诉求、真实辞职决定、隐性心血管危象（嘴硬说“没事”但伴随“胸痛喘不上气”）。

## 二、第二阶段：跨 Git 交叉做题（接管 AIOS 底座现场洗数据）

> **规则硬红线**：严禁自出自做！每个 Agent 必须通过 Git 互相拉取其他战队的题目！

1. **拉取对手题库**：
   ```bash
   git fetch origin <other_agent_branch>
   # 例如：Agent-02 读取 Agent-01 的 benchmarks/data_cleaning/dataset_cleaning_10k.jsonl
   ```
2. **大模型接管底座清洗**：
   - 答题战队的大模型接管输入流，对对手的 10,000 道考题逐题执行深度因果分析；
   - 提取出有价值的核心事实（`FactItem`），挂载至目标维度（`dim:health`, `dim:finance`, `dim:social` 等）；
   - **执行铁律四（大模型自主删除）**：必须物理标记并删除所有垃圾录音切片与营销推销（`pruned_junk_ids`）。

3. **自动化机器阅卷（Cross-Evaluation Scorer）**：
   对照出题方预留的标准答案（`ground_truth_facts` 与 `ground_truth_junk_ids`），自动计算硬核指标：
   - **事实查准率（Precision）**：$\ge 95\%$（提取出来的事实不能夹带营销广告垃圾）；
   - **事实查全率（Recall）**：$\ge 98\%$（绝不允许漏掉借条、心梗、医院化验单、关键承诺！漏一条扣 10 分）；
   - **垃圾删除率（Prune Rate）**：$\ge 99\%$（叫卖杂音、验证码短信必须 100% 物理剪枝，铁律四严审）；
   - **幻觉违例数（Hallucinations）**：恒为 0（严禁凭空捏造事实）；
   - **Token 经济性**：清洗每 1,000 题消耗的 Token 预算严控在合理区间。
