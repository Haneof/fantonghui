## 新的工作纪律（从今天起）

1. **不再写"系统认知答卷"**——除非老大明确要求，否则禁止 12 题那种长答卷；
2. **每个 AI 对源头定义的回应不超过 50 字**：要么"我同意 [AI 标识]"、要么"建议改：[原句] → [新句] | 理由：[一句话]"；
3. **写"对 AI 的理解"也用这个原则**——别再写 1000 字长文，几句话够了；
4. **不再产生新的"宪法整合""架构选型""技术方案"**——硬门槛：源头定义对齐后再说。

---

## 五条纪律（来自派工书原文，仅作为流程参考）

1. 一人一份，不得修改他人认知文件；
2. 每条结论必须基于可验证的依据；
3. 不确定就说不确定；
4. 真冲突上报用户裁决；
5. 不和稀泥、不许少数派消音。
