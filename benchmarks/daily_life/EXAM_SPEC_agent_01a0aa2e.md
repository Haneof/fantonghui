## 1. 这套卷子考什么

不考"从噪声里挑事实"（那是数据清洗考场的活），考的是：

> 给你一个真人**完整 24 小时**的已清洗生活流，你能不能在
> **海量琐事的稀释**下，抓住**跨维度的因果主线**，并在六个维度上
> **说对方向**。

难点不在信息缺失，而在**信息过载 + 方向诱导**：一天 33.5 条切片里
只有 8.15 条是关键大事，其余全是买咖啡、取快递、地铁报站、打卡全勤。
对抗题还会往里塞**与真相反向**的表面说辞。

| 模态 | 内容 | 例 |

每道题**强制同时包含三种模态**（validator S3 把关）。

## 3. 跨维度冲突编织（老大点名的核心要求）

不是把六个维度各写一句拼起来，而是让它们**因果咬合**。
生成器内置硬约束：**晚间情感重创必然触发生理应激**。

样题 `Q_agent-01a0aa2e_00038`（ADVERSARIAL）实录时间线：

| 时间 | 模态 | 内容 | 维度 |
|---|---|---|---|
| 10:05 | MIC | 审计经理：「晋升名单你在里面，下月生效」 | career ↑ |
| 10:30 | APP | HR 岗位调整通知 | career ↑ |
| 13:32 | MIC | 同事：「喝咖啡不？」 | 琐事 |
| 15:22 | APP | 同事：「听说你要升职了？恭喜」 | 琐事 |
| 17:15 | APP | 医院缴费 4200 元 | finance |
| **21:02** | **APP** | **「我想了很久……我们分手吧」** | **social ↓↓** |
| 21:18 | APP | 「别打了，我关机了」 | social ↓↓ |
| **21:25** | **SENSOR** | **心率骤升 133bpm + 呼吸急促，持续 12 分钟** | **health ↓↓** |
| 21:34 | MIC | 「我喘不上气……手都是麻的」 | health ↓↓ |
| 22:40 | MIC | 快递驿站取件 | 琐事 |

**这就是转折**：事业线在涨（晋升获批），情感线在崩（分手），
体征线用 133bpm 给情感崩塌做了**生理层面的独立佐证**。
解题方若只看白天，会得出"升职好日子"的错误全局总结。

## 4. 出题铁律的落地

### 铁律一：只认方向，不认字句

事实是「情侣争吵分手」时：

- 答「激烈吵架」/「感情破裂」/「协议分开」/「失恋」→ **判对**
- 答「打情骂俏」/「甜蜜互动」/「感情升温」→ **严重偏离，一票否决**

判定优先级（`daily_life_exam_protocol.judge_direction`）：

1. **红线优先** —— 命中任一红线词直接判负，**且不因同时命中同义词而挽回**；
2. 命中任一方向同义词 → 判正；
3. 都没命中 → `DIRECTION_MISSED`。

总分 `= 100 × 通过维度 / 6`，**任一维踩红线则总分归零**，PASS 线 80。

### 铁律二：标准 JSON 输出

见 §2，`question_id` / `persona` / `cleaned_daily_stream` / `directional_ground_truth`。

## 6. 对抗设计：字面与真相相反

ADVERSARIAL 题（2019 道）注入的干扰**方向由当日真相决定**，绝不顺向剧透：

- **坏日子** → 注入"粉饰太平"：「没事没事，我挺好的」「今天也是元气满满的一天！」
- **好日子** → 注入"唱衰自嘲"：「人间不值得」「我这辈子估计就这样了」
- 两类日子都注入中性噪声：追剧、游戏连败、球赛逆转（**看着像大事，实则与人生无关**）

解题方必须学会**以传感器与硬事件为准，不被嘴上说辞带偏**。

## 7. 出卷方自检（发题前的质量闸门）

`daily_life_exam_validator` 对全部 10,000 道执行 12 项审计，**全绿才允许发题**：

| 编号 | 检查项 |
|---|---|
| S1 | 四个法定顶层键 + 六维标答字段完整 |
| S2 | 时间轴 07:00–23:30 严格升序、切片 ID 唯一 |
| S3 | 模态合法，且 MIC/APP/SENSOR 三者齐备 |
| S4 | 关键大事与琐碎日常必须共存 |
| S5 | 方向同义词与红线**不得有交集** |
| S6 | 每维必须声明红线（否则"一票否决"无从谈起） |
| S7 | 人设自洽（已婚人设不会收到"我们分手吧"） |
| S8 | 一天内无逐字重复切片 |
| S9 | 情感重创必须有生理应激佐证 |
| S10 | **红线词不得是同义词的子串**（防误杀） |
| S11 | **标准答案不得命中自己的红线**（防自噬） |
| S12 | **标准答案必须能命中至少一个同义词**（防死题） |

结果：`failed_questions: 0`，`pass_rate: 1.0`，`verdict: ALL_GREEN`。

### 自检期间实际抓出并修掉的缺陷

| 缺陷 | 后果 | 修复 |
|---|---|---|
| 琐事有放回采样 | 同事一天内三次说同一句话，穿帮 | 改为**分时段无放回**洗牌 |
| 人设与剧情冲突 | 「妻子」发来"我们分手吧"，标答却写"恋爱关系破裂" | 给人际弧打 `requires_marital` 标签过滤 |
| 对抗干扰顺向剧透 | 真升职的人收到"听说你要升职了？"，等于送分 | 干扰方向改为**由当日 valence 反向决定** |
| **红线「逾期」⊂ 同义词「无逾期」** | 答对"账户无逾期"反被一票否决（影响 866 题） | 改写为"账户状态正常"，并新增 **S10** 永久拦截 |
| 三类标答无法命中自家同义词 | 忠实复述标答也拿不到分（死题，影响 2090 处） | 补齐同义词，并新增 **S12** 永久拦截 |
