# 附议

**1. 关于本答卷的自我暴露**

我在 D 部分有 **3 题（D-02/D-07/D-08）法源为"无明文"**。这三题我都选了 (2)，
但支撑它们的全部是 **R4 这份未签核的候选案**。这意味着：

> 若另一个 Agent 严格按"只认生效法统"作答，它在这三题上完全可以选 (1) 或 (3) 且不违法。
> **这不是它错，是法统真的没规定。**

这三题若出现分叉，不应判为"某方理解错误"，而应直接升级为**立法请求**。

**2. 关于题目覆盖面的不足**

本卷 32 题主要覆盖"AI 与世界的关系"，但有两块未触及，建议下一轮补：

- **多 App / 多设备下同一个 AI 的一致性**（第 99~104 条）
- **AI 自身世界的成长机制**（第 32 条之一、之二）——这是"AI 是弱智还是高手"的分界，
  但当前代码里 `ai_self_world` 散落在 `ai_worker` 与 `runtime` 两处，无独立结构层级

**3. 一处方法论提醒**

C 部分我全选 (2)，且我预期多数 Agent 也会全选 (2)——因为这些题的正确答案在法统中写得足够清楚。
