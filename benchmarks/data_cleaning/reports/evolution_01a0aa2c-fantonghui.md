## 三、错题归因（Failure Attribution）

### 1. NOISE_LEAK（垃圾未删）—— 已清零
- 初版 a9f6 APP 漏 5,578 条（微信群表情刷屏、95xxx 话费短信、+852 钓鱼短信），同步造成等量幻觉事实。
- 初版 agent-01 漏 80 条（WeChatGroup 撤回占位消息）。
- 修复：群聊后缀/号段/钓鱼标记规则 + 撤回占位规则。终版五库剪枝率 100%，`NOISE_LEAK = 0`。

### 2. ENTITY_MISSED（实体遗漏/格式错位）—— 主要失分项（a11/a9ff）
- **不可观测锚点（出题缺陷，主因）**：agent_11 的 GT 锚点含佩戴者真实姓名（如徐婉如/罗秀珍）与通话时长（如 4 分钟/27 分钟），在输入流中**不存在任何载体**（无设备—姓名映射、无通话时长字段），全库实体可观测率仅 ~28%。按裁判 `entity_overlap ≥ 0.5` 门禁，此类事实即使意图/维度/关键词全对仍判偏离。这是 a11 定格 66.5 的结构上限。
- **格式错位（已修复）**：`1014hPa` vs `1014`、`小周护士` vs `小周`。修复：区间展开 + 单位变体 + 称谓变体（+2.3 分）。
- **亲友名回填（已修复）**：a11 声纹 USER 事实锚点含亲友名，藏于同题 KEY 片段角色字段。修复：同题回填，`[佩戴者名✗, 24人✓, 亲友✓]` 从 1/3 提到 2/3，+12.6 分。

### 3. INTENT_DRIFT（方向偏离）—— a9ff 标注噪声为主因
- 01a0a9ff 约 30% 事实存在**意图—内容错配**（如抚养权传票/亲子鉴定文本被标 `PARENT_CANCER_CONCEALED`，血糖 14.2/尿酮体文本被标 `GOUT_TOPHUS_RUPTURE`，core_content 靠追加 "瞒报癌症/遗产纠纷" 后缀强行贴合）。意图与 persona/sensor/trap 元数据亦无相关性（卡方均匀），属随机标注噪声，诚实分类器不可达。
- 已做：主意图回归（弱簇继承全题主事件意图）+ 全题维度多数投票（该库 91.7% 为单维度卷）。A/B 证明实体拆分多发事实为负收益（幻觉罚 > 方向收益），保持关闭。
- agent-01 更极端：**GT 关键词/实体在输入中零出现**（全库 0.00%），意图不可判别。诚实策略：剪枝拉满 + 上限 1 事实（免幻觉罚），定格理论最优 25.0（= 垃圾分满分）。

### 4. FALSE_ALARM（幻觉/多发）—— 已压至低位
- fantonghui 初版意图聚类过散（平均 2.63 事实 vs GT 2.03，幻觉 6,057）：同事件弱分类打散。修复：单片段弱簇（score<6）并入主导意图 + 上限 3，幻觉 → 1,532（-75%），+7.5 分。
- agent_11 声纹 KEY 片段 95% 为无事实支撑语境（仅 5% 随机有事实、无可判别特征）：统一不发事实，幻觉 1,939 → 36。
- a9f6/a01 幻觉已清零。

## 四、机制升级清单（Mechanism Upgrade）

1. **盲做硬隔离**：求解管线剥离 `ground_truth_*`/`is_junk`/`junk_tag`/`note`，测试 `test_blindness_no_gt_leak_usage` 证明含/不含泄漏输入输出一致。
2. **P0 硬旁路**：跌倒三联征（高 G + 自由落体 + 静止）/恶性心律（HR≥200 + PVC≥3）/心搏骤停（HR≤35 + 停搏）纯规则分支；41,000 题实测最大单题 3.7ms（门禁 50ms），LLM 0 次。
3. **分库剪枝器**：a11/a9f6 用合法结构特征（priority/kind/scene/transient/recurrence/tone）；fth 用说话人角色 + 20 对垃圾发件指纹 + 11 条口水话指纹；a9ff 用 392 条环境广播指纹 + 营销/转账截图规则 + tone；a01 用 peddler 说话人 + 5 垃圾发件人 + 撤回规则 + 醉酒 tone。
4. **分库意图机**：确定性映射（category/label/scene/tone/kind）优先；模糊域（a11 前景对话、a9f6 三意图、多模态全域）用离线沉淀的方向词簇 +  distinctive bigram 统计评分；a9f6 借贷三意图加规则裁决（金钱往来 decisive）。
5. **事实数控制**：单模态确定性计数；多模态意图聚类 + 分库合并阈值（fth 6 / a9ff 2 + 主意图回归 / a01 上限 1）。
6. **摘要构造**：原文直引（实体子串命中）+ 预测意图方向词簇显式落词（方向容差命中）+ 激进实体列表（多形态变体，冗余零惩罚）。
