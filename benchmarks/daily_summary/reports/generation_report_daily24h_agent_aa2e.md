## 一、单卷结构（严格按出卷规范）

每卷 = 一个人的完整 24 小时（07:00~23:30），标准 JSON 四要素：

```json
{
  "question_id": "QD_agent-aa2e_00001",
  "persona": {"name": "…", "gender": "…", "age": …, "occupation": "…", "city": "…"},
  "cleaned_daily_stream": {"date_span": "07:00~23:30", "events": [ {time, channel, content} × 16~24 ]},
  "directional_ground_truth": { global_daily_summary + 5 个维度标答 }
}
```

### 输入数据（cleaned_daily_stream）
- **三通道混编**：MIC 对话切片（80,563 条：家人/同事/领导/客户/邻居/陌生人）、
  APP 通知与聊天（89,964 条：微信工作群、恋人留言、银行还款、外卖、快递、新闻）、
  SENSOR 体征宏观摘要（30,000 条：晨起静息心率、全天步数、情绪冲击时刻的剧烈心率
  波动、睡眠时长、压力指数）；
- **关键大事 × 海量琐碎**：每卷 3 条主线弧事件链（事业弧+情感弧+财务事件）嵌入
  8~12 条买咖啡/取快递/超市砍价/追剧等低熵日常，事件按时间戳严格排序；
- **跨维度冲突转折内置**：情感冲击统一安排在 19:00~22:40 引爆（如白天被当众批评 +
  晚间收到「我们分手吧」+ 手环同刻记录心率骤升至 112~136bpm），传感器读数与
  剧情极性联动（负向冲击 → 应激性心动过速 + 睡眠 4.2~6.0h；喜事 → 兴奋性短暂
  上浮后自行回落）。

### 方向性语义标答（directional_ground_truth，6 维全覆盖）
每一维均含四件套：`core_content`（基准事实）+ `acceptable_directions`（可接受方向
同义词簇）+ `forbidden_directions`（绝对偏离一票否决红线）+ `anchor_entities`（关键实体）。

| 维度 | 标答内容 | 红线示例 |
| :--- | :--- | :--- |
| global_daily_summary | 全天核心剧情主线（如「白天高光晚间坠落的冰火两重天」） | 双喜日答成「情绪崩溃」 |
| dim:health | 静息心率/步数/睡眠 + 冲击时刻心率骤升归因（情绪性 vs 器质性） | 应激心动过速答成「器质性病变」或「剧烈运动所致」 |
| dim:social | 人际关系核心翻转（分手/求婚/亲病/催债翻脸…） | 分手答成「甜蜜互动/打情骂俏」→ 一票否决 |
| dim:emotion | 情绪主基调（3×3 极性矩阵：先抑后扬/乐极生悲/双重打击…） | 崩溃日答成「轻松愉悦」 |
| dim:finance | 资产负债变动（还款/月供/工资/浮亏/转账金额锚点） | 正常还款答成「逾期违约」或「暴富」 |
| dim:career | 工作推进与受阻（被批/晋升/裁员/甩锅/翻车…） | 被裁答成「升职加薪」 |

## 二、高熵组合空间

- **人物**：30 姓 × 30 名 × 24 职业 × 16 城市 × 双性别 × 年龄段 → 实测 9,985 个不重复画像；
- **剧情**：14 条事业弧（晋升/裁员/甩锅/演示翻车/欠薪/拒稿/门店整改/大单/挖角…）
  × 14 条情感弧（分手/求婚/母病/催债绝交/离婚谈判/相亲/寻宠/婚讯…）
  × 8 类财务事件 → 实测 1,564 种三线组合，最大重复仅 18 卷（金额/时刻/人名/城市再扰动）；
- **极性矩阵**：负负（双重打击）2,547 卷、正正（双喜临门）1,786 卷、先扬后抑 1,736 卷、
  先抑后扬 2,510 卷、单点冲击 1,421 卷——六种人生走向全覆盖；
- **质检**：10,000 卷全量校验 —— 通道齐备（MIC+APP+SENSOR）、时间戳有序且在
  07:00~23:30 界内、六维标答四件套齐全、零未填充占位符：**violations = 0**。

## 三、出题铁律自查

1. ✅ 标答只锚方向不锚字句：每维给出 4~7 个可接受同义方向 + 3~5 条一票否决红线
  （例：「情侣争吵分手」→「感情破裂/协议分开/被分手」均判对；「打情骂俏/甜蜜互动」判死）；
2. ✅ 标准 JSON 四字段：`question_id` / `persona` / `cleaned_daily_stream` / `directional_ground_truth`；
3. ✅ 事实自洽：标答全部由发生器与剧情事件同一上下文生成，不存在标答与流水矛盾；
4. ✅ 确定性可仲裁：SEED 固定、重跑 SHA256 逐字节一致；
5. ✅ 铁律二：全部为新增文件，无任何历史篡改。
