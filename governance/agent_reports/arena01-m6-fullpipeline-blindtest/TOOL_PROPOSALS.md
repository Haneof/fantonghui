# 《新机制发明与新工具提议（ToolProposal）》

> 老大约法三章：测试的终点是**机制与工具**。以下为本次海量盲测发明并已用
> 纯代码实现的新型算子（均已过 `ToolProposalPipeline` 契约登记：
> `tests/tools/test_blindtest_tool_proposals.py`），以及一条在研提议。

## 工具 #1：自适应时序压缩算子 `AdaptiveTemporalCompactor`

- **位置**：`src/aios_core/tools/adaptive_temporal_compactor.py`
- **能力缺口**：50Hz/100Hz 传感器波形缺乏"平稳期结晶、突变期独立"的自适应压缩，
  高频直写数据库会撑爆端侧存储（宪法第十章第三十三条）。
- **机制**：单遍流式（O(1) 驻留内存）；心率通道用慢速 EMA 基线 + 25bpm 突变阈值
  + 90 秒不应期（防回落二次误报）；IMU 通道用 4.0g 冲击阈值；相邻窗口均值位移
  ≥30% 判定运动相态切换；平稳段结晶为"区间均值观测"，突变独立为"波形摘要观测"
  （≤16 点下采样 digest，可供驾驶舱回放）。
- **实测收益**：7,776,000 条原始采样 → 2,532 条观测，**过滤率 99.97%（压缩比
  3071×）**；注入的 4 次跌倒冲击与 6 次心率突变 **100% 零漏检、零重复**；
  原始波形落库行数恒 0。
- **验证**：`tests/tools/test_adaptive_temporal_compactor.py`（4 用例）。

## 工具 #2：双透镜虚拟索引投影器 `DualLensVirtualIndexProjector`

- **位置**：`src/aios_core/tools/dual_lens_projector.py`
- **能力缺口**：铁律2 要求"历史绝不篡改、只在今天打标签"，但 AS_KNOWN /
  ANNOTATED 双读面此前缺乏工程化的只读投影件；旧式全量级联重算曾造成
  210 次 API 算力雪崩。
- **机制**：在不可变事实账本 + 注解注册表之上做纯读投影——AsKnown 透镜按
  "注解诞生时刻晚于被注视时刻则不可见"裁剪历史视图；每次投影前后校验
  SHA-256 聚合指纹，漂移即抛 `LensConsistencyError`；注解引发的下游失效只能走
  `SingleHopCascadeIsolator`（深度==1，`max_hops>1` fail-closed）。
- **实测收益**：120 条 3 年历史事实 + 今天诈骗重估注记——投影任意次，
  历史指纹逐字节不变；单跳失效仅触碰 10 个直接下游，100 个二级节点完好，
  LLM 重算 0 次。
- **验证**：`tests/tools/test_dual_lens_projector.py`（4 用例）。

## 在研提议 #3：向量化边缘压缩内核（尚未实现，立项建议）

- **观察**：工具 #1 纯 Python 单遍处理 7.78M 采样耗时 25.3s（约 33μs/样本）。
  端侧实时流（50Hz IMU 持续输入）需要 <1μs/样本 的量级。
- **提议**：以 `array`/内存视图批量接口重写内层循环，或下沉为 C 扩展；
  契约面保持 `compact(samples) -> CompactionResult` 不变。
- **预期收益**：压缩吞吐 30~100×，使"百万级波形清洗"进入秒级。

## 机制性结论（超越单点工具）

1. **"指针 + 按需解包"是全系统省 Token 的第一机制**：建议、注解、总结、对话
   凡跨层引用一律 ObjectRef 化，原文只在最后一公里微切片物化；
2. **"单跳隔离 + 未来预算窗口"替代无界级联**：失效只标直接下游，深层节点
   由调度器在未来独立窗口逐级处理——可审计、常数算力、零雪崩；
3. **"对抗发生器 + 地面真值清单"应成为所有盲测的制式**：测试只与发生器的
   `GeneratorManifest` 对照（注入数/检测数/过滤率/指纹），杜绝自编自答。
