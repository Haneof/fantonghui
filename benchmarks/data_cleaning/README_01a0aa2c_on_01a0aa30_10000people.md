## 判分口径（对手方向性标答 → 分数）

- **方向 0.7**：答卷每个维度的总结覆盖了该维锚点 `core_claim` 中多少**方向概念**；同义表达、
  以及 `acceptable_directions` 里的等价方向都计入容差（概念层比对，不做字面 n-gram 抠字眼）。
- **实体 0.3**：锚点 `required_entities`（本人 + 关键联系人）的命中率。
- **红线**：`redline_criteria` 的 `contradicted_claim` 为**硬断言**判据 ——
  ① 红线里的数字+单位（如 `125bpm`）出现在答卷且所在小句无否定语境；或
  ② 红线断言了某个**结局状态**（任务完成 / 取消终止 / 资金到账 / 关系断交 / 确诊危象 / 承诺当收入…），
  答卷在**同一小句**里以相反极性断言同一状态并带上话题词；
  ③ 兜底：同一小句出现两个以上红线特有实词且无否定语境。命中即该维度 0 分、整题 FAIL。
  语境以**小句**为单位（逗号/分号/句号切分），所以"任务保留，**不是**撤销"这类澄清句不会被误判。
- **达标线**：`final_score ≥ 80.0` 且无红线命中（`PASS_LINE`）。
- **方向反转审计**（独立于红线的更强检查）：逐维比较"标答断言 / 答卷否认"的不可逆结局，
  话题词或金额必须对得上才算数；本次 10,000 题审计结果为 **0** —— 本队答卷没有把标答否认的结局说成事实。

## 与并行会话同题库交付的关系（独立复核，非重复计分）

同一条分支上的**并行会话**也在同一支对手卷上交付了一份成绩（路径在
`benchmarks/daily_summary/answers|reports/…_on_daily-examiner-01a0aa30.*`，题解器
`src/aios_core/ingest/daily_solver_aa30_01a0aa2c.py`），自报 **均分 100.0 / PASS 100%**（8 秒、0 LLM）。
两份交付互不覆盖、代码零共享，差异是**解题方式**与**判分口径**，一并列在这里以免被误读成同一件事：

| 维度 | 并行会话（模板枚举引擎） | 本次交付（通用显著性摘要器） |
| --- | --- | --- |
| 解题方式 | 从盲卷输入流枚举模板 + 意图对齐（8 职业 × 8 社交 × 6 健康 × 10 财务） | 角色→维度线索 + 切片显著性排序 + 姓名加权 + 实体补位，不做题库特化 |
| 判分口径 | 意图级方向命中 + 红线否决 | 概念覆盖 0.7（含同义簇）+ 必需实体 0.3，达标线 ≥80 且无红线 |
| 成绩 | 100.0 / 100% | 75.25 / 39.90% |
| 判别力自证 | 阴性对照（乱序）29.66 / PASS 0%；扰动对照 76.0 | 天花板（标答回灌）100 分 / 0 红线；负向对照 8 句零误判 |

两点结论：①两份成绩不矛盾——差距主要来自**判分颗粒度**（意图级 vs 长尾概念覆盖），
本队通用摘要器在"把锚点的全部长尾要素都写进一句话"上天然吃亏（可达性上限 0.83）；
②两份自检互补，都说明各自的裁判不是橡皮图章：一份证明"错配会被打到 29.66"，
一份证明"标答回灌能拿满分、题面引用不会被误判红线"。
官方若采用意图级判分，应引用并行会话那一份；若采用严格覆盖式判分，本报告即为其口径下的真实成绩。

## 诚实披露 / 已知取舍

1. **覆盖式方向分天然偏向"写全"**：分数奖励把锚点要素逐条写进总结，而本队策略是"只写最显著的事实"，因此绝对值偏低；
   天花板自检（100 分可达）+ v1/v2 消融 + 可达性审计三件套，是用来把"分数低"与"能力弱"区分开的证据。
2. **判分器是本队自研口径**，不是官方裁判；报告里 `judge_semantics` 写明了每一条判据，便于对手复核或反驳。
3. **错题档案截断**：6,010 条未达标题中写盘 1,500 条（红线优先 + 总分升序），其余以指标形式保留在报告里。
4. **红线命中 0** 表示"本队答卷没有断然说出标答否认的方向"，不代表细节全对 —— 细节问题体现在方向覆盖分与错题档案里。
5. 从未修改对手分支文件：题目与标答全部经 `git show`（含 `.xz` 流式解压）只读获取，本分支只新增上述交付物。
