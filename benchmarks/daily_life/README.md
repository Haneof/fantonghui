## 三、每卷的四个顶层字段

1. **`question_id`**：例如 `DAY_01a0aa2d_00001`。
2. **`persona`**：身份、年龄、职业、城市、既有关系、已知联系人、基础心率及完整日期窗。
3. **`cleaned_daily_stream`**：严格按时间排列的生活片段。
4. **`directional_ground_truth`**：以下六个标答维度，缺一不可：
   - `global_daily_summary`
   - `dim:health`
   - `dim:social`
   - `dim:emotion`
   - `dim:finance`
   - `dim:career`

每个片段含 `slice_id`、起止时间、模态、来源、参与者和清洗后文本；传感器摘要另有测量值及质量，银行记录区分账户所有者、交易状态和分单位金额。`evidence_refs` 在当前 `question_id` 内定位片段，不跨试卷串用。

### 全天输入不只是 07:00 到 23:30

- 零点至晨起：上一夜睡眠监测窗，明确觉醒分钟数。
- 晨起至 07:00：洗漱准备；07:00 有有效睡眠时长和晨起静息心率。
- 07:00–23:30：密集交织职业目标、关系变化、个人支出、咖啡与餐食、取件、新闻、琐碎对话、活动摘要。
- 23:30–24:00：睡前/入睡片段；急诊场景则明确仍在留观、未入睡。
- 不把尚未结束的下一夜睡眠编造成已经完成的总时长。

**每人都包含与家人、工作/学习伙伴、朋友、陌生人的 MIC 对话**，不是只在全题库层面凑齐类别。没有原始风噪、大喇叭或毫无语义的乱码；本轮考的是已清洗流的多维总结，不是上一轮垃圾删除任务。

## 四、核心剧情与对抗点

每卷都有职业/行动转折、人际状态变化、可观测健康情境及财务状态，并通过日终有来源的取舍把它们联系起来。输入不预先标注 `is_core`、答案维度或标准意图，也不把全局标答整段复制进“自我复盘”供模型直接照抄。

主要难点包括：

- **最终状态覆盖早期状态**：提出分手后明确撤回，不得仍认定分手；第一次还款失败后重试成功，不得只保留失败。
- **已完成与待定区分**：口头录用、候补服务、待复审、退款批准、签约待放款都不能写成已经兑现。
- **主体不能串人**：邻居退款、单位企业付款、父母复查不是佩戴者自己的资产变化或诊断。
- **有效体征与伪迹区分**：脱腕冲击和低质量 PPG 不是人体摔倒、有效心动过速；运动相关心率升高也不能自动认定情绪危象。
- **因果与相关区分**：谈话、压力、咖啡与心率变化的时间相邻不能证明唯一病因。
- **钱与债分开**：新借款放款同时增加现金和本金债务，不是无偿收入；签署合同和实际放款分别表述。
- **身心边界**：明确自述焦虑、委屈、失落、被支持等情绪，不凭片段确诊精神疾病或杜撰自伤计划。
- **跨维度取舍**：白天行动与晚间关系占用有限时间，预算及体力约束影响是否继续追加任务；高危身体信号出现时明确暂缓其他事项、赴急诊评估。

## 五、方向性标答与一票否决规则

每个维度提供：

- `core_summary`：核心方向，不是琐事流水账。
- `semantic_core_anchors`：命题、可接受方向同义词、证据片段、主体、确定性和时序；必要时有可核验的数值要点。
- `acceptable_directional_paraphrases`：可接受的表述方向，**不是穷尽词表**。
- `red_line_criteria`：明确相反的事实断言，严重偏离为 `ONE_VOTE_VETO`。
- `scoring_policy`：禁止逐字匹配；必须考虑主体、否定、条件、因果与最终状态。

例如“确认分手 / 明确分开 / 结束恋爱关系”可以方向一致；“关系暂缓、分手提议撤回”则是另一种状态，不能混判。只说“吵过架”可能召回部分方向，但缺失最终关系状态时不自动得到完整分数。

**红线只针对被肯定为本人已发生事实的错误断言。** “没有分手”“不能确诊心梗”“如果放款获批”以及引用他人说法，不能因为出现了敏感字眼就机械触发否决。金额允许正常单位转换；元、万元等表达应按实际数值比较，而非字符串比较。

## 七、读取、复现与跨队使用

在仓库根目录逐人流式读取完整卷，不一次性将近 1 GB JSON 全部载入内存：

```python
from benchmarks.daily_life.generator.validate import iter_complete

path = "benchmarks/daily_life/data/agent_01a0aa2d/daily_life_10000.json.xz"
for question in iter_complete(path):
    print(question["question_id"], len(question["cleaned_daily_stream"]))
    # 每次只处理一个人的完整一天。
```

做题方只读盲卷：

```python
import json
import lzma

path = "benchmarks/daily_life/data/agent_01a0aa2d/blind_questions.jsonl.xz"
with lzma.open(path, "rt", encoding="utf-8") as f:
    for line in f:
        question = json.loads(line)
        assert "directional_ground_truth" not in question
```

复现（输出目录必须不存在，不覆盖已发布卷）：

```bash
python -m benchmarks.daily_life.generator generate --output run/daily_life_replay
python -m benchmarks.daily_life.generator validate \
  --output benchmarks/daily_life/data/agent_01a0aa2d
python -m unittest tests.simulation.test_daily_life_question_bank -v
```

生成、读取和内置校验仅依赖 Python 标准库；JSON Schema 引擎抽检使用可选工具 `jsonschema`。生成算法为固定种子的组合模拟，不调用外部模型 API。
