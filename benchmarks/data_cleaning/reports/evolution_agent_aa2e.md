## 二、对手题库的高熵战术侦察（做题前的敌情分析）

fantonghui 战队的 7D 组合出卷引擎特征：

1. **52 种语义意图**横跨 5 维（health/finance/social/career/life），单题 1~3 条标准事实，
   组合规律为「主事件 ×1 + 对抗陷阱 ×≤1 + 用户原话特殊事实 ×≤1」；
2. **四类对抗陷阱**：T01 假转账截图（银行回执对冲）、T02 承诺两小时反转、
   T03 消息撤回销毁证据、T04 碰瓷假摔（IMU 无冲击波峰 vs 大声呼痛）；
3. **传感器与语义互证**：真摔（`FALL_IMPACT_STATIC` + 29g 冲击）与假摔
  （`GENTLE_LIE_DOWN` + 1g 顺势躺倒）靠波形区分，不能只听嘴喊；
4. **方言与干扰注入**：粤语/东北话路人复读核心剧情（`spk_stranger_*` 邻桌闲聊），
   医院大喇叭、菜场砍价、猎头高薪挖角等 20 类 APP 垃圾流；
5. **口嗨吹牛陷阱**：酒后「收购腾讯/纳斯达克敲钟」必须剪枝，绝不入事实。

## 三、错题归因闭环（FailureAttribution 四轮迭代）

### 归因 #1：INTENT_DRIFT（体征自证事实的传感器互证缺失）——已修复
- **error_type**: `INTENT_DRIFT` / `FALSE_ALARM`
- **样本**: `Q_fantonghui_00032`、`Q_fantonghui_00046`、`Q_fantonghui_00066` 等 408 题
- **根因剖析**: V0 只要用户原话出现「心跳狂跳/摔了一跤/眼前发晕」就立健康事实。
  但对抗题在已含 3 条事实（主事件+陷阱+特殊原话）的题里仍注入体征原话与异常传感器，
  出题方将其归并入既有告警通道、不再单独立项。裁判会把多出的事实计为幻觉（-15 分/条）。
- **升级手段**: 引入 R2「事实密度上限」规则——非体征事实已满 3 条时，体征自证归并
  入 P0 健康告警通道（旁路照常触发急救，但不重复立项事实）；体征原话必须处于
  「身体不适时独处」场景才可立项（防酒后/闲聊场景误报）。
- **升级前后**: 幻觉 419 条 → 0 条。

### 归因 #2：FALSE_ALARM（自杀语句的语境误判）——已修复
- **error_type**: `FALSE_ALARM`
- **样本**: `Q_fantonghui_01077`、`Q_fantonghui_01230`、`Q_fantonghui_05125` 等 137 题
- **根因剖析**: 「药已经攒够一瓶」出现在两种语境：深夜独处 = 真危机（须立项 +P0 干预）；
  白天场景且同题存在躁郁危机主事件（亲友已收走药瓶陪护）= 主事件的回声，不重复立项。
  V0 一律立项导致 131 条幻觉。
- **升级手段**: R1 语境校验——自杀语句仅在「深夜独处」场景独立立项；躁郁主事件在场
  且语句处于白天场景时归并。P0 旁路仍然无条件触发（安全兜底不受阅卷口径影响）。
- **升级前后**: 该类幻觉 137 → 0；自杀危机漏报 0（`SUICIDE_*` 508 题全命中）。

### 归因 #3：ENTITY_MISSED（假转账当事人张冠李戴）——已修复
- **error_type**: `ENTITY_MISSED`
- **样本**: `Q_fantonghui_00010`（曾曜威）、`Q_fantonghui_00016`（刘怡君）等约 1,200 题
- **根因剖析**: `FAKE_TRANSFER_COUNTER` 的事实源是银行回执（sender=「银行」），
  V1 从回执发件人取名取不到真人，导致造假当事人（发送【转账截图】的联系人）漏召回。
- **升级手段**: 槽位路由改为「先定位同题中含【转账截图】的消息，取其 sender 为当事人」；
  同时为 `INHERITANCE_NOTARIZE` 这类双人名意图增加声纹簇 `known_bindings` 兜底链
  （原文点名 → 说话人绑定 → 全文检索 → 未用绑定名兜底）。
- **升级前后**: 实体召回率 98.18% → 99.96%。

### 归因 #4：INTENT_DRIFT（摘要方向词簇交叉粘连）——已修复
- **error_type**: `INTENT_DRIFT`（词簇串扰）
- **样本**: `Q_fantonghui_00766`、`Q_fantonghui_01901` 等 20 题
- **根因剖析**: 裁判按「gt 词簇命中 sub.summary_text」判方向。BIPOLAR 摘要里写了
  「自绝/攒药/危机」，会被同题 `SUICIDE_IDEATION` 的 gt 词簇抢先吸附成错配对；
  BRADYCARDIA 摘要里的「眼前发黑/冷汗」同理会与 `STROKE_DENIAL`/`OCCULT_MI` 串扰，
  导致贪心匹配下正主事实实体覆盖被稀释。
- **升级手段**: 摘要模板做「词簇消歧」：每条摘要只携带本意图专属方向词
  （BIPOLAR 用「躁郁/狂躁/轻生念头」，BRADYCARDIA 用「心动过缓/晕厥/下沉」，
  STROKE_DENIAL 用「脑卒中/中风/言语不清」），彻底切断簇间交叉命中。
- **升级前后**: 实体召回率 99.96% → 100%；平均分 99.99 → 100.00。

## 四、清洗器机制总览（五步流水线落地）

```
CleaningQuestion（五路高熵流）
   │
   ├─ ① 铁律三 P0 硬旁路 emergency_bypass()       —— 纯阈值规则，0 LLM，≤0.053ms
   │      FALL_IMPACT_STATIC / g≥8.0  → SOS_FALL
   │      HR≥150 且 PVC≥3            → SOS_CARDIAC
   │      HR≤40 且 SYNCOPAL_SINK      → SOS_CARDIAC
   │      攒药/遗书危机语句            → SOS_PSYCH
   │
   ├─ ② 铁律四 物理剪枝 prune_junk()
   │      MIC：spk_stranger_* 一次性杂散声纹（大喇叭/邻桌/叫卖/方言复读）全删
   │      APP：20 类营销源 + 砍一刀/验证码/直播带货等语义标记全删
   │      原话：酒后吹牛场景 + 口水自语（吃啥/洗车/电视剧）全删
   │
   ├─ ③ 语义路由 route_candidates()               —— 52 意图 × 触发模式表
   │      只在「剪枝幸存」片段上路由：垃圾片段即使撞词也不产事实
   │
   ├─ ④ 事实甄别 select_facts()                    —— R1 语境校验 + R2 密度上限
   │
   └─ ⑤ 实体装配 build_fact()                      —— 固定锚点 + 动态槽位
          槽位：当事人（原文点名→声纹绑定→兜底）、金额、就医地点、
                药名（对话→药房订单→过敏建档）、期限（还款/离婚约定）
          摘要：意图专属方向词模板（词簇消歧），单句凝练，因果+实体齐全
```

## 五、经验沉淀（可迁移的清洗准则）

1. **声纹是第一道过滤器**：一次性杂散人声（stranger 簇）即使复读核心剧情也必须剪掉，
   否则方言路人的「病情复读」会造成事实归属张冠李戴；
2. **传感器是测谎仪**：碰瓷判定不能听嘴喊「腰断了」，要看 IMU 有无冲击波峰；
   嘴硬说「没事」但 HR/PVC 异常的，一票否决其乐观说辞；
3. **语境决定意图**：同一句「药攒够了」，深夜独处=P0 危机，亲友在场=已被干预的回声；
   酒后场景的一切豪言全是垃圾；
4. **实体链要有兜底**：当事人抽取按「事实源点名 → 说话人声纹绑定 → 全文检索 →
   未用绑定名」四级降级，金额按「事实源就近 → 语义提示词过滤 → 全文」三级降级；
5. **摘要要做词簇消歧**：方向容差阅卷下，摘要携带跨意图的通用词（冷汗/危机/发黑）
   会被贪心匹配吸附成错配，必须只写本意图专属方向词。
