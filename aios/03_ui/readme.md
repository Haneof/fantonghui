# 03_ui · UI 与交互（待开工）

**状态：** 空目录。等 OS M3（interactd 五级介入通道 API）稳定后开工。

## 定位

UI 不是"画界面"，是宪法 6.8 交互系统的物理呈现层：五级介入通道（不介入/静默视觉/触觉/骨传导/受控执行）+ 振动语义 + 屏幕分区。

## 与 OS 的接口契约（见 01_os/docs/OS总体架构设计_V0.1.md §12）

- OS 提供：interactd 介入通道 API、振动语义表、显示请求协议
- UI 提供：屏幕分区规格（外腕主区/侧边光带/内腕区）、抬腕贴耳骨传导交互规范、马达能力

## 已有设计参考（来源：克劳德5框架 V1.0，待按宪法对齐）

- 息屏是常态，信息局部亮起、3 秒自动消退
- 操作深度 ≤ 2 层，无 App 图标无菜单栏
- 振动语义可自定义（用户与 AIOS 形成"触觉语言"）
