## 三、治理废黜与拆分明细台账（Abolished & Split Registry）

为防止开发团队在实现过程中再度引入旧方案遗毒，特明确以下废黜与拆分条目：

1. **废黜 `workspace.open` 逐步喂料（旧 M2-009）**：
   - **原因**：字段并列诱导大模型多轮网络往返，AI 自身状态排在第 9 位被边缘化，首字延迟超过 6 秒；
   - **替代方案**：全面替换为 `M2-016 Single-Shot Cockpit Manifest` 单次看盘聚合器与 `M2-017 心智四步序`。
2. **废黜无条件任务全量遍历（旧 M2-005）**：
   - **原因**：无触发条件字段，任何唤醒全量 Prefill 进模型，日耗 3000 万 Token；
   - **替代方案**：全面替换为 `M2-005R 两级条件驱动任务调度引擎`（机械快轨 0 Token，未就绪 DORMANT 隐形）。
3. **拆分旧 M1-011（多维对齐比较与机械变化检测）**：
   - **原因**：机械物理量计算与高阶语义推断混淆；
   - **替代方案**：拆分为 `M1-011A 纯机械变化检测（GPS/步频）` 与 `M1-011B 实体认知差异比较器`。
4. **废黜非先导骨传导常开设计（旧硬件规范）**：
   - **原因**：日常托腮挠头动作极易导致私密传音误触公放；
   - **替代方案**：全面替换为 `M2-018 超宽频微震先导 FSM`（未震动骨传导物理断电）。
