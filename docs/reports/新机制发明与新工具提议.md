## 二、ToolProposal 1：自适应时序压缩算子

### 2.1 契约

```python
ToolProposal(
  object_id="tool_adaptive_compressor_001",
  capability_gap="海量生理时序存储爆炸与冲击波形漏检",
  use_cases=["心率平稳期压缩", "IMU 50Hz 宏观提取", "摔倒撞击高保真保留"],
  current_limitations=["固定2h窗口 variance 门槛不自适应", "IMU 窗口固定5s未按活动自适应"],
  proposed_interface={
    "class": "AdaptiveTimeSeriesCompressor",
    "methods": ["compress_heart_rate_stream", "compress_imu_stream"],
    "compression_target": ">95% flat, 0 miss spike"
  },
  expected_benefit="存储写入降低 95%，P95 压缩延迟 <1ms，冲击零漏检",
  validation_plan="盲测 50k IMU + 5k HR，断言压缩率与漏检率",
)
```

### 2.2 机制创新

**对比基线**：`EdgeCleaner.HR_QUIET_SECONDS=7200` 固定窗口 + `PulseMergeWindow 5s` 固定聚合。

**新机制三点**：

1. **方差滞回**：`variance < 9.0` 且 `|Δ|<15bpm` 视为平稳，持续 `7200s` 才刷出一个 `CompressedWindow(mean/min/max/variance)`；`var > 9.0` 且持续 5 点则视为 `variance_breakout` 立即切窗，避免临界抖动。
2. **冲击独立窗**：`|Δ| ≥ 15bpm` 或 `peak_g ≥ 3.0` 单独生成 `is_anomaly=True` 窗口（`sample_count=1`），不与前后平稳段合并，保证波形因果不被均值稀释。
3. **IMU 宏观状态机**：`5s` 窗内 `peak_g`→`macro_state`（`静止/平缓走动/剧烈跑动/疑似摔倒撞击`），`is_impact` 仅当 `peak_g ≥ 3.0`，单日 4.3M 点压至 17k 事件（250×）。

**伪代码**：

```python
def compress_heart_rate_stream(samples):
  windows = []
  cur = []
  for ts,val in sorted(samples):
    spike = abs(val - cur[-1][1]) >= 15.0
    var = variance(cur_vals + [val])
    if spike or duration >= 7200 or (var>9 and len(cur)>=5):
      windows.append(emit(cur))
      if spike: windows.append(anomaly(ts,val)); cur=[]
      else: cur=[(ts,val)]
    else: cur.append((ts,val))
  return windows
```

## 三、ToolProposal 2：双透镜虚拟索引投影器

### 3.1 契约

```python
ToolProposal(
  object_id="tool_dual_lens_001",
  capability_gap="老王案双透镜视图切换 O(n) 拷贝与 210 次雪崩",
  use_cases=["AsKnown/Annotated 零拷贝切换", "多关键词共现检索", "单跳隔离防雪崩"],
  current_limitations=["全量事实拷贝", "无界级联重算"],
  proposed_interface={
    "class": "DualLensVirtualIndexProjector",
    "methods": ["view_as_known", "view_annotated", "co_search_with_lens"],
    "isolation_depth": 1
  },
  expected_benefit="视图切换 O(1)，内存增量 O(注解数)，P95 <3ms，LLM 0 次",
  validation_plan="2k 事实 + 1 注记，断言哈希不变、透镜隔离、切换延迟",
)
```

### 3.2 机制创新

**对比基线**：`BiTemporalEpistemicLens.query_historical_slice` 每次重建 `HistoricalSliceView` 且调用方若深拷贝则 `O(n)`。

**新机制三点**：

1. **零拷贝虚拟映射**：`LensView` 持有 `ledger` 引用 + `annotation_index` 指针，`view_as_known(cutoff)` 仅做 `learned_at <= cutoff` 过滤（`O(注解数)`），事实表 `O(1)` 指针复用，不分配新 `dict`。
2. **单跳隔离机械截断**：`SingleHopCascadeIsolator` `max_hops=1` 硬拒绝 `>1` 请求，`direct_stale=10`，`prevented=210`，`llm_recompute=0`（审计可核）。
3. **共现检索透镜感知**：`co_search_with_lens(keywords, lens)` 在虚拟视图上做 posting-AND + `overlay` 叠加，`hits` 为事实 `fact_id`，`latency_ms` 与 `virtual` 标记一并返回。

**伪代码**：

```python
class DualLensVirtualIndexProjector:
  ledger: ImmutableFactLedger
  def view_as_known(self, cutoff):
    t0 = perf_counter()
    overlays = [a for a in self._annotations if a.learned_at <= cutoff]  # 0 for old cutoff
    facts = self._collect_facts_limited()  # O(1) pointer
    self.stats.record_switch((perf_counter()-t0)*1000)
    return LensView(facts=facts, overlays=overlays, is_virtual=True)
```
