## 1. 审查范围

M0-014 只冻结主动系统的五类长期对象及基础 fixture：`Task`, `Wake`, `Session`, `Action`, `Outcome`。本任务不实现 M2 调度器、观察器运行时、外部动作重试引擎或完整恢复编排。

任务书要求：Task 持久保存 type/state/goal/priority/next_wake/deadline/dependencies/completion/cancel/executions/outcomes；Wake 保存 source/hits/evidence/priority/dedupe；Session 固定世界快照；Action 与 Outcome 分离；Action 使用稳定 execution_id；Outcome 可以保持 UNKNOWN。模型上下文不得替代 Task，消息送达不得等同帮助成功。

## 2. Task 契约

冻结字段继续保持既有十类 TaskType 与 TaskState。`title` 明确非空；`next_wake_at` / `deadline` 必须是 timezone-aware datetime；`timezone_name` 必须是有效 IANA 时区名。

引用语义：
- `reason_refs`, `execution_refs`, `outcome_refs` 是创建原因/执行收据/结果历史，必须 pinned revision；
- `goal_ref`, `dependency_refs`, `related_entity_refs` 保持通用导航引用语义，允许 floating，不在本任务擅自扩大 pinned 规则。

Task 的未来工作状态是持久世界对象，不依赖模型上下文存活。

## 3. Wake 契约

Wake 与 Observation、Task 均为独立 WorldObject。冻结 `wake_source`, `wake_state`, `rule_id`, `first_hit_at`, `last_hit_at`, `hit_count`, `evidence_refs`, `priority`, `dedupe_key`。

`evidence_refs` 是“为什么这次 Wake 发生”的历史依据，必须 pinned。时间先检查 aware，再通过 UTC instant 比较，避免跨时区/DST 直接 datetime 比较错误。

M0-014 不实现触发调度算法；重复命中合并/冷却/调度运行时留给后续主动闭环任务。

## 4. Session 契约

Session 保留 `wake_ref`, `snapshot_world_revision`, `operation_ids`, `checkpoint`, `session_state`。`wake_ref` 若存在必须 pinned，因为会话必须能回放“由哪个 Wake revision 启动”。`snapshot_world_revision` 与 operation/checkpoint 共同提供后续恢复基础。

本任务不实现完整 session executor；只冻结恢复所需的持久字段。

## 5. Action 与 Outcome 分离

Action 冻结稳定非空 `execution_id`、`action_type`、`action_status`、可选 pinned `task_ref`、payload 与 expected_outcome。

Outcome 是独立 WorldObject；`action_ref` 必须 pinned，`evidence_refs` 必须 pinned，`outcome_state` 非空且允许保存 `unknown`。

因此以下状态严格分离：
- Action 已执行/已完成；
- 消息或通知已送达；
- 用户是否接受；
- 用户目标是否改善；
- 学习是否真正发生。

专项测试证明 `ActionStatus.COMPLETED` 可以同时对应 `Outcome.outcome_state = unknown`，也可以后来出现 `user_rejected` 等结果；不会把动作执行成功误写成现实帮助成功。

## 6. SQLite 与持久化边界

五类对象均通过现有 SQLiteWorldStore 正常序列化、写入、读取，引用 revision 保持不变。

M0-009 durable persistence revalidation 继续覆盖这些对象：构造后若通过 list mutation 把 Task provenance 或 Wake evidence 注入 floating ref，commit 在写入前重新验证并以 `INVALID_ARGUMENT / persistence_revalidation_failed` 原子拒绝，world revision 不增长。

没有修改 `sqlite_store.py`。
