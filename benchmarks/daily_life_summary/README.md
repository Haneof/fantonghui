## 每一份试卷是什么

四个顶层字段严格为：

```text
question_id
persona
cleaned_daily_stream
directional_ground_truth
```

- `persona`：唯一 person_id / 姓名、职业、城市、日期、时区、联系人、日初背景。`synthetic=true` 明示虚构。
- `cleaned_daily_stream`：按时间排序的切片；每片含 `slice_id`、`timestamp`、`end_timestamp`、`modality`、`speaker_or_source`、`location`、`content`，部分附带体征和实际交易。
- 一天覆盖 **00:00–24:00**：00:00–07:00 是夜间统计片段；07:00–23:30 是密集生活流；23:30–24:00 是日界休息片段。睡眠统计窗明确可能包含前夜入睡时间，不冒充从当天零点才开始睡。
- 07:00 后无超过 65 分钟的未说明时间空洞；每个半小时区间优先放入普通观察，再增加其他切片。片段时间可以重叠，如日界账本、步数摘要和同期语音。
- 每人均包含 MIC、APP、SENSOR，以及部分个人笔记。小事包括餐饮、交通、取上周已付款包裹、家人问候、同事闲聊、阅读、天气、新闻转述、文件整理等。
- 工作上午状况、下午确认、晚间社交变化、自述情绪、体征响应、夜间个人取舍形成跨维度主线；不只放几个重大事件凑成一天。
- 输入不含 `importance` / `is_core` / `scenario_id` / `semantic_intent`。片段 ID 的末尾是随机排列，不用低序号暗示核心事件。

## 六维方向性标答

`directional_ground_truth` 包含且仅包含：

1. `global_daily_summary`：人生当天主线，以及工作与个人关系／家庭安排的取舍。
2. `dim:health`：睡眠、体征轨迹、信号有效性、步数；区分运动负荷、静息偏快和脱腕伪迹。
3. `dim:social`：关系的最终状态，而非只抓最早一句争吵或传言。
4. `dim:emotion`：有原话依据的主观情绪及其变化，不从情绪标签诊断疾病。
5. `dim:finance`：承诺、申请、实际收入、退款、还本、新增负债、普通支出、日终余额。
6. `dim:career`：通过、整改待定、取消范围、延期、纠错、拒绝加单或待决邀请。

每一维提供：

- `semantic_core_anchors`：核心事实、意图、至少 **3 条可接受的方向同义表述**、实体、证据片段、必要的结构化数值。
- `redline_criteria`：与证据相反的**完整命题**、`VETO` 严重性及证据；不是禁词列表。
- `grading_notes`：明确方向判定、否定／引用／假设语境，以及“计划不等于完成”等边界。
- 全局维度另有 `causal_constraints`：一条可由用户明确自述支持的取舍关系，以及不能擅自升级成疾病因果的限制。

### 必须保留的判分区别

- **确认分手**：接受“关系破裂”“双方分开”；肯定为“甜蜜互动”“已经复合”违反红线。
- **撤回分手并继续交往**：接受“争吵后和好”；不能仍把早先气话当作最终已分手。
- **125bpm 出现在快步运动中**：不能说成静息情绪危象；体征与情绪同现也不等于已经确诊心梗。
- **脱腕 6.2g / 无效 PPG 0**：重戴有效心率已经澄清，不应写成人体真实摔倒、心搏骤停。
- **结算方说明明天付款**：当天不得算到账；**已到账贷款**必须同时承认债务，不能算净赚。
- **单项任务取消**不等于被全面解雇；**拒绝额外任务**不等于已经辞职。
- **照护与工作都改到明早**不代表冲突已解决：相应组合会明确第二次改期尚未批准。
- 写“并非分手”“电影里的人分手了”不能因为出现“分手”二字就被判红线。阅卷要比较主体、肯否、时态、状态和依据。

## 读取与复现

生成器仅需 Python 标准库；执行项目全库测试仍需项目开发依赖。独立 Schema QA 另需 `jsonschema`。

```bash
# 从仓库根目录读取一个完整 JSON 示例
cat benchmarks/daily_life_summary/agent_01a0aa30/example_person_00001.json

# 流式读取正式压缩卷；每次仅解析一份试卷
python - <<'PY'
import json, lzma
path = 'benchmarks/daily_life_summary/agent_01a0aa30/exams_10000_people.jsonl.xz'
with lzma.open(path, 'rt', encoding='utf-8') as f:
    for line in f:
        exam = json.loads(line)
        # 在这里交给考官或转换格式；不要把标答传给做题模型
        print(exam['question_id'], len(exam['cleaned_daily_stream']))
PY

# 在新目录复现，拒绝覆盖已发布题库
PYTHONPATH=src python -m simulator.daily_life_exam generate \
  --count 10000 --seed 2026091603 --output run/daily-exam-replay

# 对完整发布包执行内容级 QA；不做解答或评分
PYTHONPATH=src python -m simulator.daily_life_exam validate \
  benchmarks/daily_life_summary/agent_01a0aa30

# 可选：独立 Schema 全量复核
python -m pip install jsonschema
python scripts/validate_daily_life_schema.py \
  benchmarks/daily_life_summary/agent_01a0aa30/exams_10000_people.jsonl.xz \
  --output run/daily-schema-recheck.json
```

固定种子与相同代码可字节级复现压缩数据；manifest 记录两份生成源码的哈希。XZ 归档、标准 JSON 样例均有独立 SHA-256。示例字段无需外部站点解析；Schema 文件是 `schemas/daily_life_exam.schema.json`。
