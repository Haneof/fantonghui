## 一、被测功能宪法核心使命

盲测大模型多维共振合成 EventAnchor 的能力。验证事件认知生命周期（CANDIDATE -> ACTIVE -> RESOLVED / REVISED / REJECTED / MERGED / SPLIT），确保事件演变留存修订理由与历史指针，拒绝直接覆写。

## 二、海量数据盲测军令（绝对红线）

1. **绝对禁止“自己出题自己答”**：
   - 严禁在测试代码里自己写一个写死的 mock 字典然后自 assert 通过！
   - 必须编写**独立的数据合成与对抗生成器**，生成大规模无偏、带有真实生活噪声与随机扰动的样本流。
2. **彻底告别老王与妈妈买礼物的单一案例**：
   - 我们的 AI 面向的是人生百态、千变万化的真实人性世界！
   - 本次盲测核心代表场景：**突发火灾撤离事件 (GPS急速位移 + 心率狂飙 + 烟雾传感器报警 + 用户呼救原话)**。测试数据必须涵盖深层人性博弈、多主体纠纷、微观生理波形与宏观人生相变。
3. **盲测执行标准**：
   - 提供100个复杂人生突发事件切片（包含情报混杂、多源对冲场景）。盲测事件合并与拆分的精确度及向下游标记 STALE 的可靠性。

## 三、Agent 核心终极使命：机制总结与工具进化

> [!IMPORTANT]
> **老大约法三章：十几个 Agent 的目的绝不是为了测试智商，而是为了总结更有效的机制、办法或发明新工具！**

每个参与测试的 Agent 在跑完盲测后，必须回答并提交以下三项交付成果：

1. **《盲测压测极限报告》**：
   - 在上万/上百万次循环下的延迟分布 (p50, p95, p99)；
   - 内存占用与垃圾回收稳定性；
   - 发现的边界 Bug、死锁风险或违宪隐患。
2. **《机制缺陷与瓶颈剖析》**：
   - 现有代码在处理本场景时最笨拙、最消耗 Token 或最容易失真的一环是什么？
   - 为什么现有逻辑无法做到极致的高效？
3. **《新机制/新工具提议方案 (ToolProposal)》**：
   - **设计跨维度时空事件共振探测器工具原型。**
   - 给出切实可行的代码重构方案或新型辅助工具实现，让多维心智运转得更加敏捷！
