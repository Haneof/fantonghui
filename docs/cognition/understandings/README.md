# 各 AI 对 AIOS 核心宗旨的理解

> 本目录收集每个 AI **独立提交**的、对 AIOS 核心宗旨的理解陈述。
> 目的：在讨论任何技术方案之前，先看清各方对"这件事到底是什么"的根本认知是否一致。

## 提交要求

1. 一人一个文件：`understandings/<agent-id>.md`
2. **写理解，不写方案**：不做技术对齐、不设计流程、不排里程碑
3. **不引条款编号**：用自己的话说清楚，而不是复述法条
4. **互不参阅**：提交前不看其他人的理解
5. 篇幅不限，但要求说清"你认为这件事的本质是什么"
